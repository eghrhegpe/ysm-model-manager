# YSM 项目术语对照表

> 统一全项目命名，避免 UI/代码/文档三套叫法。

---

## 核心名词

| UI 文案 | 代码字段 / Go 类型 | 说明 |
|---------|-------------------|------|
| YSM / MMD / VRC / 材质包 / 光影包 / 蓝图 | `rtype`（字符串枚举） | 界面一律叫资源类型名称，不混用"模型""资源" |
| 仓库 | `FilesRoot`（配置路径） | 用户配置的根目录，含 `ysm/` `resourcepacks/` 等子目录 |
| 整合包（UI） | `Instance`（Go 结构体） | 用户可见的 Minecraft 实例，UI 不出现"实例" |
| 创作者（UI） | `author`（数据字段） | 社区站点里的作者实体；文件名 `[作者]` 解析用 author |
| 启用 / 禁用（仓库） | 加/除 `.ban` 后缀 | 仓库层面，不打禁用则不碰文件 |
| 安装 / 卸载（整合包） | 物理复制/硬链接/删除 | 整合包层面，涉及文件增删 |
| 推送（仓库→整合包） | `PushSingle*` | sidebar 标签已用"推送" |
| 拉取（整合包→仓库） | `PullSingle*` | sidebar 标签已用"拉取" |
| 同步（整体状态） | `GetInstanceSyncStatus` | 双向对比检测 |

## UI 专有名词（语感统一）

| 当前 | 建议 | 理由 |
|------|------|------|
| "仓库元老" | **资历最深** / **最早模型** | "元老"易误解为整合包，实际展示最早 10 个模型 |
| "健康度" | **仓库评分** / **质量评分** | "健康度"太宽泛，实际=禁用率+重复率加权 |
| "今日推荐" | **每日推荐** | 语感更自然 |

## 给 AI 的缩写版

```markdown
# YSM 项目术语（AI 快速参考）

## 核心概念
- **仓库** = 用户配置的 `FilesRoot` 根目录（含 ysm/ resourcepacks/ 等子目录）
- **整合包** = 用户可见的 Minecraft 实例
- **实例** = 代码内部对整合包的称呼（`ListVersionInstances`）
- **资源类型** = YSM / MMD / VRC / 材质包 / 光影包 / 蓝图（对应 `rtype`）
- **创作者** = 社区站点里的作者实体（有 avatar、presetSearches、type 标签）
- **作者** = `.ysm` 文件名 `[作者]作品名.ysm` 里解析出的字符串

## 动作动词
- **启用 / 禁用** = 仓库层面，给文件加/除 `.ban` 后缀
- **安装 / 卸载** = 整合包层面，物理复制/硬链接/删除文件
- **推送** = 仓库 → 整合包
- **拉取** = 整合包 → 仓库
- **同步** = 双向或整体同步状态检测
- **导入** = 外部文件 → 仓库（走导入队列、重命名、去重）

## UI 文案规范
- Toast 前缀：✅ 成功 / ⚠️ 警告 / ❌ 错误 / 🌐 网络 / 📂 目录 / ⏳ 进行中
- 配置缺失统一：**"请先配置 {游戏目录|仓库目录|存储路径|{类型}目录}"**
- 按钮/标签 ≤ 4 字；tooltip ≤ 12 字；toast ≤ 30 字
```
