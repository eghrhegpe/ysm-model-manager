# ADR-311-d1：测试纪律：禁 mock 被断言谓词（自证）+ 判别样本 + 变异探针

- **状态**：✅ 已采纳（Accepted）
- **日期**：2026-10-09
- **决策人**：Jieling（人类首席架构师）、AI 代理
- **关联主 ADR**：ADR-311

---

## 背景（一句）

锐评 2026-10-08 收口测试可信度：`preview-3d/` 现有 116 处 `vi.mock`，须区分「隔离外部依赖的正当替身」与「mock 掉**被断言行为**的谓词——自证（断言的是替身而非真实现，测试无效）」。

## 决策（三行）

- **禁自证**：测试**不得** `vi.mock` 掉被断言行为的谓词 / 主体模块；`vi.mock` 仅限外部依赖与副作用边界（`three`、`three/addons/**`、`@backend/**`、Loader、`@/wasm/**`、`@moeru/three-mmd*`、`@pixiv/three-vrm*`、`storage`、`document`/canvas/WebGL）。判据：断言的目标是**被测主体自身**的真实导出，而非被 mock 模块的导出。
- **判别样本**：核心纯函数 / 关键守卫逻辑的测试**必须正反例齐全**（返回值判真 + 判非真两侧），单侧即欠债，缺则补。
- **变异探针**：关键守卫（所有权 / dispose 顺序 / 让权 / 通路裁决）须经**变异实证**——手动改错实现，测试须转红，实证结论写进测试注释（既有范式：`environment-capability.test.ts`「dispose 顺序收敛」两例）。

## 后果（一句）

既有测试按此口径复审：自证案例改行为断言、单侧样本补反例、关键守卫补变异实证（本次只修明确违规，不推翻正当的依赖隔离替身）。回退 = `git revert` 对应审计批次。
