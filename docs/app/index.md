# 🖥️ 网页版（预留）

> 此页面为 **Web 版入口占位**。当前 YSM 模型管理器以桌面应用（Wails v3）为主，Web 版仍在规划中。

---

## 当前状态

| 项目 | 状态 |
|------|------|
| 桌面应用（Windows / macOS / Linux） | ✅ 已发布 |
| 网页版（WebAssembly） | 🚧 预留规划，未开工 |

## 规划方向（暂定）

- 核心解析逻辑（YSMParser）已编译为 **WASM**，具备 Web 移植基础
- 前端为原生 Web Components + Shadow DOM，与浏览器环境天然兼容
- 3D 预览基于 Three.js，Web 端可直接复用

> 待桌面端功能稳定后，评估 Web 版可行性。此页面届时将替换为实际应用入口。
