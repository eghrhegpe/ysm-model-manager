## 🐛 Bug 修复

### 1. `GetRepoRoot("")` 跨类型搜索失效
- **位置**：`resource_bindings.go:69-87`
- **症状**：仓库页"全部"标签跨类型搜索返回 `""`，因为 `StorageSubDir("")` 返回 `""` 后 `GetRepoRoot` 兜底也返回 `""`
- **修复**：在 `GetRepoRoot` 加 `if rtype == "" { return cfg.FilesRoot }` 兜底
- **影响**：解锁 YSM+MMD+VRC+材质包+光影包+蓝图跨类型搜索

### 2. 下载完成时创作者网格整页闪烁
- **位置**：`frontend/js/views/app-content/index.js:565-579`
- **症状**：`avatar:refresh` 触发 `showSiteView(currentSite)` 整页重渲染，下载完成时闪烁
- **修复**：改为遍历 `.cr-creator-card` 按 `dataset.name` 匹配，只替换 `<img>.src`；找不到才回退整页重渲
- **影响**：消除下载完成时的视觉闪烁

### 3. `gh-striped` class 写错属性
- **位置**：`frontend/js/features/community/data.js:14-19`
- **症状**：测试时发现 `gh-striped` 被拼到了 `style="width:50%;transition:width 0.3s gh-striped"`，本应是 CSS class
- **修复**：把 `gh-striped` 从 style 移到 class 属性
- **影响**：striped 动画背景能正常触发（虽然 CSS 端目前没定义 `.gh-striped` 选择器，未来加即可）

### 4. `tryFetchModels` 并发请求不会启动第 2、3 个
- **位置**：`frontend/js/features/community/data.js:125-140`
- **症状**：`waitForReady(p2Ready)` 传的是原始 `false`，闭包里 `flagRef` 是值拷贝，setTimeout 改了外层 `p2Ready` 也看不到 → 2s/4s 延迟启动机制完全失效
- **修复**：`flagRef` → `getReady`，传函数 `() => p2Ready`，每次 `check()` 重新读取外层变量
- **影响**：镜像竞速策略真正生效，2s/4s 延迟启动第 2/3 个请求
