## 复核纪律

- 审计报告是**时态快照**（写于审计当日）。代码还债后，原文保留不变，新增「状态复核」段记录现实。
- **归档条件**：复核结论为"不构成当前代码债务"或"已偿还"的报告，移入 `archive/`。
- 防倒退：`scripts/check-adr-drift.mjs` 对活报告的复核段 + 代码断言做 CI 校验。
- 新增审计：命名 `audit-r{N}-{主题}-{日期}.md`，落入本目录即自动进入侧边栏「审计」分组。
