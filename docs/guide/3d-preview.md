# 3D 预览与模型详情

## 它能做什么

点击仓库中的文件后在右侧面板预览：YSM 模型解析为 2D 骨骼图 / 3D 骨骼模型，支持旋转缩放、详情查看、资源包内容浏览与骨骼导出。

## 打开方式

在「模型仓库」中点击任意模型文件 → 右侧预览面板自动加载。

## 操作步骤

### 1. 模型预览（YSM）

- 点击 `.ysm` 模型 → 右侧显示 2D 骨骼图与 3D 骨骼模型
- 支持旋转、缩放查看
- 高面数模型（>2000 cubes）可能卡顿，稍等片刻

### 2. 模型详情

- 查看模型元数据、骨骼结构摘要
- 贴图/纹理加载自模型内部资源（blob URL 缓存管理）

### 3. 资源包 / 光影包详情

点击资源包类文件 → 显示包内内容详情（材质、贴图等）。

### 4. 骨骼导出

预览面板支持**骨骼数据导出**（`preview-bone-export`），可将模型骨骼结构导出复用。

## 常见问题

**Q：预览不显示 / 一直转圈？**
A：部分高面数模型解析耗时；确认文件完整（损坏的 ysm 会解析失败并提示）。

**Q：贴图不显示？**
A：模型贴图需内嵌在 ysm 中；外部引用的贴图路径需与模型在同一目录。
