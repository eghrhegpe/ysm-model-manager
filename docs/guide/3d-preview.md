# 3D 与 2D 预览

在文件树中选中模型文件，右侧预览面板即刻显示内容。面板宽度可拖拽调节（约 160–500px）。

## 预览页签

预览面板顶部是三个页签（标签按文件类型显示）：

- **📄 详情**：文件基本信息（文件名、大小、类型等），所有类型都有；
- **🏗️ 骨骼**：2D 骨骼图（仅 YSM 模型）；
- **🎨 3D**：3D 立体预览（仅 YSM 模型）。

## YSM 模型：详情页签

- 摘要信息：作者、标签、描述等（来自文件元数据）；
- 底部按钮：
  - **🎮 整合包**：该模型属于某个整合包时显示，点击切换到整合包页签查看；
  - **🏷️ 标签** / **📄 重命名**：快捷打开对应弹窗；
  - **📋 导出骨骼名**：导出该模型的骨骼列表为 `<模型名>_bones.txt`（无骨骼的模型按钮置灰）。

## YSM 模型：2D 骨骼图

骨骼页签显示模型的立方体结构 2D 渲染图：

- **交互**：左键点住全窗放大 · 滚轮缩放 · 左右拖拽旋转（提示条显示在视图底部）；
- **工具**：「👁 骨骼名」开关显示/隐藏骨骼名称；「🔍 放大」全屏查看（600×600）。

## YSM 模型：3D 预览

切换到 3D 页签即进入全屏覆盖式的 3D 查看器：

- **视角**：鼠标拖拽旋转、滚轮缩放；右侧面板提供「🎥 镜头」选项——相机环绕 / 模型自身旋转开关与速度滑杆；
- **📷 截图**：顶部菜单可按 当前视角 / 正面 / 45° / 侧面 / 后45° 拍摄，或「全套」一次导出全部视角（PNG 保存到本地）；
- **右侧面板**：📐 模型统计（立方体/纹理信息）、🎨 纹理、🦴 骨骼面板；
- **退出**：按 ESC 或点「✕ 关闭 3D」；
- **调试**：按 F 键循环调试视角（开发用）。

> 打开 3D 预览需要本机支持 WebGL。若画面空白，先更新显卡驱动，或在 3D 页签查看右上角错误提示。

## 其他格式的预览

| 类型 | 预览内容 |
|------|---------|
| 资源包（.zip） | 详情页签显示 pack.png 缩略图 + 包元信息（见《资源包预览》） |
| 整合包蓝图（.litematic 等） | 详情 + 材料列表 + 体素 3D 预览（见《整合包蓝图预览》） |
| 光影 / 音乐 / 视频 / 杂项 | 仅详情信息（文件名、大小等） |
| 外部格式（MMD/VRC 等） | 详情 + 简略视图提示（暂不支持深度解析） |

## 常见问题

- **预览没有 3D 选项**：该格式不支持 3D 解析（仅 YSM 模型支持）；
- **3D 预览很慢**：模型立方体/骨骼数量大或文件体积大时属正常现象。可关闭自动旋转减少负载；
- **网页版导入大文件卡住**：网页版单文件上限 100MB（桌面版同口径），超过此大小的文件建议直接放入仓库文件夹后用桌面版打开。解码时若浏览器标签页短暂卡顿，属正常现象（WASM 解码期间的 peak 内存可达文件体积的 3-4 倍）；
- **截图保存到哪里**：PNG 文件保存到本地（浏览器下载路径），文件名含视角标识。
