# 高级筛选

## 它能做什么

在仓库中按多个维度组合筛选 YSM 模型：关键词、骨骼数范围、立方体数范围、纹理尺寸范围、标签——多条件同时生效（AND），精确找到目标模型。

## 打开方式

「模型仓库」文件树工具栏 →「⚙️ 筛选」按钮（悬停提示「高级筛选」）。

## 操作步骤

### 1. 筛选条件

| 条件 | 说明 |
|------|------|
| 🔍 关键字（模型名） | 名称匹配，留空匹配所有（最多 100 字符） |
| 🦴 骨骼数 | 最小—最大区间（如 30–60 根） |
| 🧊 立方体 | 最小—最大区间（区分低模与高模） |
| 🖼 纹理尺寸 (px) | 最小—最大区间（贴图分辨率） |
| 🏷️ 标签（留空不限） | 按 [标签管理](./tags.md) 中的标签过滤，输入框右侧会异步显示「已有标签: xxx, yyy」提示 |

### 2. 应用与组合

- 点「🔍 应用 (Enter)」或在任意输入框按 Enter 提交；结果 toast「🔍 找到 N 个匹配」，无匹配时提示「🔍 无匹配模型（已应用筛选）」
- 多个条件同时生效（AND 关系），例如「骨骼 ≥ 40 且 标签=机甲」
- 区间只需两端都填时才校验「最小值不能大于最大值」

### 3. 清除 / 取消

- 「取消 (Esc)」或点遮罩 → 不应用直接关闭
- 「🧹 清除全部」→ 移除全部筛选条件，恢复完整列表
- 筛选生效期间，工具栏下方的筛选面板会显示当前条件，其「清除」按钮可一键清空

## 常见问题

**Q：筛选后列表为空？**
A：条件组合过于严格，放宽范围或清除部分条件。注意筛选只作用于 YSM 模型的解析数据（骨骼/立方体/纹理），未解析成功的文件不会命中数值条件。

**Q：标签条件怎么填？**
A：弹窗会异步加载已有标签提示（「已有标签: xxx, yyy」），照提示输入即可；标签的添加与编辑见 [标签管理](./tags.md)。

**Q：能按作者筛选吗？**
A：用工具栏「🎨 作者 ▾」下拉——列出仓库中解析出的所有作者及数量，点击即以作者名回填搜索框。
