# 高级筛选

## 它能做什么

在仓库中按多个维度组合筛选模型：关键词、骨骼数范围、方块数范围、贴图数范围、标签——精确找到目标模型。

## 打开方式

「模型仓库」页面 → 搜索框旁「⚙️ 高级筛选」按钮。

## 操作步骤

### 1. 筛选条件

| 条件 | 说明 |
|------|------|
| 关键词（keyword） | 名称匹配 |
| 骨骼数（min/max Bones） | 按骨骼数量范围过滤（如 30-60 根） |
| 方块数（min/max Cubes） | 按方块数量范围过滤（低面数 vs 高面数） |
| 贴图数（min/max Tex） | 按贴图数量范围过滤 |
| 标签（tag） | 按 [标签管理](./tags.md) 中的标签过滤，留空不限 |

### 2. 组合使用

多个条件同时生效（AND 关系），例如「骨骼 ≥ 40 且 标签=机甲」。

### 3. 清除 / 取消

- 取消（Esc 或点遮罩）→ 返回不应用
- 清除 → 移除全部筛选条件，恢复完整列表

## 常见问题

**Q：筛选后列表为空？**
A：条件组合过于严格，放宽范围或清除部分条件。

**Q：标签条件怎么填？**
A：弹窗异步加载已有标签提示（"已有标签: xxx, yyy"），输入后按提示补全即可。
