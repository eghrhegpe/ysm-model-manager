# 备份与迁移

## 它能做什么

完整备份 YSM 模型管理器的三类数据——配置、操作日志与模型仓库——并迁移到新电脑。

## 操作步骤

### 1. 备份配置

程序配置保存在 `%APPDATA%\YSM-Model-Manager\ysm_config.json`（**不是** exe 同目录；旧版 exe 旁的配置会在启动时自动迁移过来），包含：

- 文件存储路径与各类型独立路径、游戏根目录
- 链接模式、主题、下载镜像源、体素上限
- 运行阈值（扫描缓存、下载超时、日志上限、体素、版本检查等）
- 窗口位置与大小（含双屏相对坐标）

备份：复制这个文件即可；恢复：放到新电脑相同路径（`%APPDATA%\YSM-Model-Manager\`）。

> ⚠️ **这份文件只覆盖「路径 + 链接模式 + 主题 + 运行阈值 + 窗口」这一档设置。**
> 界面偏好（字号/字体/密度/动画）、启动默认页、界面语言、3D 相机与渲染偏好、键位映射、
> 收藏的创作者等几十项设置存放在浏览器的本地存储（localStorage）里，**不在这个文件中**，
> 复制 `ysm_config.json` 带不走它们（详见下方「哪些设置会跟着迁移」）。

### 从设置页一键导出（推荐）

「设置 → 环境 → 备份与迁移」可一键把**两档设置合并导出**为单个 JSON
（`ysm-settings-export.json`，同样写在应用数据目录下），新电脑上再点「导入设置」即可整体恢复：

- 导出包含磁盘配置（路径/链接模式/主题/阈值/窗口）+ 浏览器本地存储偏好（字号、键位、3D 场景与渲染偏好、工坊筛选态、收藏创作者等）
- 导入前会自动把当前配置备份成 `ysm_config.json.bak-时间戳`（最多保留 10 份），路径类字段按原样导入，
  导入后需到「设置 → 环境」确认文件存储路径/游戏根目录指向本机有效路径
- 导出文件含应用版本与导出版本号，旧版程序无法导入新版文件（会提示升级程序后重试）

> 该导出/导入为桌面端功能（ADR-344-d1）；网页版设置走浏览器 IndexedDB，语义不同，后续单独立项。

### 2. 备份操作日志（可选）

同目录下的 `ysm-import-logs.json` 记录导入/下载/扫描等操作日志（上限 500 条），想保留历史记录可一并备份。

### 3. 备份模型仓库

模型仓库是纯文件集合（统一存储路径下 `ysm` / `resourcepacks` / `shaderpacks` / `schematics` / `mmd` / `vrchat` 各子目录），直接复制整个目录即可。若仓库较大，建议压缩后传输。

> 注意：仓库里的 `.recycle` 回收站目录也在仓库内，会随目录一起备份。

### 4. 迁移到新电脑

1. 安装程序（[下载与安装](./install.md)）
2. 复制 `ysm_config.json` 到新电脑的 `%APPDATA%\YSM-Model-Manager\`
3. 复制模型仓库目录到新位置
4. 启动程序，到「设置 → 常规」确认文件存储路径与游戏根目录指向新位置（路径变了，配置里的旧路径需要更新）
5. 若使用硬链接模式，点「🔄 重新应用」重建链接
6. **重设不随配置迁移的偏好**（见下一节清单）

## 哪些设置会跟着迁移

程序设置分两处保存，这是换机时最常见的困惑来源：

| 存放位置 | 覆盖的设置 | 复制 `ysm_config.json` 后 |
|---------|-----------|------------------------|
| `ysm_config.json`（配置文件） | 文件存储路径、游戏根目录、链接模式、主题、下载镜像源、体素上限、运行阈值、窗口位置 | ✅ 自动恢复 |
| 浏览器本地存储（localStorage，存于应用数据目录内） | 界面字号/字体/密度/动画、界面语言、启动默认页、3D 相机与渲染偏好、键位映射、收藏的创作者、上次停留页面等 | ❌ 单独复制配置文件不恢复；用「设置 → 环境 → 备份与迁移」导出/导入即可整体带走 |

**为什么第二档跟不来**：它由界面的 WebView 存在浏览器本地存储里，不在 `ysm_config.json` 中，
也不随复制单个文件而迁移。需要换机迁移时请用上面的「一键导出/导入」功能收拢这一档。

> 3D 场景能力（天空/地面/雾/水等十余项）与工坊按站筛选态属于**键族**设置——它们存在多个按场景/
> 站点拼接的键里，导出/导入已按真实键逐一收拢，无需担心漏带。

**哪些值得手动重设**（其余恢复默认通常无妨）：
- 「设置 → 常规」里的界面字号、显示字体、卡片密度、动画开关
- 界面语言、启动默认页面
- 「设置 → 3D 预览」里的相机速度、旋转模式、分辨率/帧率上限、键位映射
- 创意工坊页收藏的创作者

> 完整的键 → 存放位置对照见代码库 `frontend/src/settings-keys.ts`（设置键台账，单一事实源）。

## 常见问题

**Q：只备份配置不备份仓库可以吗？**
A：配置只记录路径与偏好，不包含模型文件；模型文件需单独备份仓库目录。

**Q：迁移后字号/键位/收藏等都丢了？**
A：旧版需要手动重设；现在用「设置 → 环境 → 备份与迁移」的导出/导入，可把这一档浏览器偏好随磁盘配置一并带走，不必逐个重设。

**Q：这些本地设置能导出成文件备份吗？**
A：能。桌面端在「设置 → 环境 → 备份与迁移」一键导出为单个 JSON（`ysm-settings-export.json`，写在应用数据目录下），新电脑导入即可恢复。旧版无此功能（`b1116645c` 起有文档无实现），升级程序后使用。

**Q：迁移后模型列表为空？**
A：确认设置页的「文件存储路径」指向迁移后的仓库目录（新电脑上盘符/路径变了，配置里的旧路径会失效）。

**Q：配置里有哪些敏感信息？**
A：配置仅含路径与外观偏好，不含账号密码；但包含仓库/游戏目录路径，公开分享时注意隐私。

**Q：旧电脑用的旧版本，配置格式兼容吗？**
A：兼容。新版启动时会自动迁移旧位置（exe 同目录/上一级）的配置文件，字段升级（如旧 `repoRoot` → 新 `filesRoot`）也在加载时自动完成。
