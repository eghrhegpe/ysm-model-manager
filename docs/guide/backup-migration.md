# 备份与迁移

## 它能做什么

完整备份 YSM 模型管理器的三类数据——配置、操作日志与模型仓库——并迁移到新电脑。

## 操作步骤

### 1. 备份配置

程序配置保存在 `%APPDATA%\YSM-Model-Manager\ysm_config.json`（**不是** exe 同目录；旧版 exe 旁的配置会在启动时自动迁移过来），包含：

- 文件存储路径与各类型独立路径、游戏根目录
- 链接模式、主题、下载镜像源、体素上限
- 窗口位置与大小

备份：复制这个文件即可；恢复：放到新电脑相同路径（`%APPDATA%\YSM-Model-Manager\`）。

### 2. 备份操作日志（可选）

同目录下的 `ysm-import-logs.json` 记录导入/下载/扫描等操作日志（上限 500 条），想保留历史记录可一并备份。

### 3. 备份模型仓库

模型仓库是纯文件集合（统一存储路径下 `ysm` / `resourcepacks` / `shaderpacks` / `schematics` / `mmd` / `vrchat` 各子目录），直接复制整个目录即可。若仓库较大，建议压缩后传输。

> 注意：仓库里的 `.recycle` 回收站目录也在仓库内，会随目录一起备份。

### 4. 迁移到新电脑

1. 安装程序（[下载与安装](./install.md)）
2. 复制 `ysm_config.json` 到新电脑的 `%APPDATA%\YSM-Model-Manager\`
3. 复制模型仓库目录到新位置
4. 启动程序，到「设置 → 基础设置」确认文件存储路径与游戏根目录指向新位置（路径变了，配置里的旧路径需要更新）
5. 若使用硬链接模式，点「🔄 重新应用」重建链接

## 常见问题

**Q：只备份配置不备份仓库可以吗？**
A：配置只记录路径与偏好，不包含模型文件；模型文件需单独备份仓库目录。

**Q：迁移后模型列表为空？**
A：确认设置页的「文件存储路径」指向迁移后的仓库目录（新电脑上盘符/路径变了，配置里的旧路径会失效）。

**Q：配置里有哪些敏感信息？**
A：配置仅含路径与外观偏好，不含账号密码；但包含仓库/游戏目录路径，公开分享时注意隐私。

**Q：旧电脑用的旧版本，配置格式兼容吗？**
A：兼容。新版启动时会自动迁移旧位置（exe 同目录/上一级）的配置文件，字段升级（如旧 `repoRoot` → 新 `filesRoot`）也在加载时自动完成。
