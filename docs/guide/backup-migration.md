# 备份与迁移

## 它能做什么

完整备份 YSM 模型管理器的两份数据——配置与模型仓库——并迁移到新电脑。

## 操作步骤

### 1. 备份配置

程序配置保存在 `ysm_config.json`（与 exe 同目录），包含路径、链接模式、主题等全部设置。

- 备份：复制 `ysm_config.json` 即可
- 恢复：放到新环境 exe 同目录

### 2. 备份模型仓库

模型仓库是纯文件集合，直接复制整个仓库目录即可。若仓库较大，建议压缩后传输。

### 3. 迁移到新电脑

1. 安装程序（[下载与安装](./install.md)）
2. 复制 `ysm_config.json` 到新 exe 目录
3. 复制模型仓库目录到新位置
4. 启动程序，确认设置页路径指向新仓库位置（[首次配置](./first-setup.md)）

## 常见问题

**Q：只备份配置不备份仓库可以吗？**
A：配置只记录路径，不包含模型文件；模型文件需单独备份仓库目录。

**Q：迁移后模型列表为空？**
A：确认设置页的「模型仓库路径」指向迁移后的仓库目录（路径变了配置里的旧路径会失效）。

**Q：配置里有哪些敏感信息？**
A：配置仅含路径与外观偏好，不含账号密码；但包含仓库/游戏路径，注意隐私即可。
