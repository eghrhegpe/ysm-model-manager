# 批量重命名

## 它能做什么

对仓库中多个文件一键批量重命名：支持预设模板、统一规则应用，适合整理模型命名风格。

## 打开方式

在「模型仓库」勾选多个文件 → 右键或工具栏选择「📝 批量重命名」。

## 操作步骤

### 1. 选择文件

- 勾选需要重命名的文件（至少一个）
- 未选择文件时应用会提示「没有需要重命名的文件」

### 2. 配置命名规则

- 在弹窗中填写新名称模板 / 规则
- 支持「📋 预设」菜单切换常用命名模板（展开/收起）

### 3. 应用

- 点击「✅ 应用重命名」或按 `Enter`
- 应用前确认文件列表，避免误改

## 常见问题

**Q：重命名后模型找不到？**
A：重命名只改文件名，模型内容不变；文件树会刷新到新名称。若按名称搜索，请用新名称。

**Q：预设在哪里管理？**
A：弹窗「📋 预设」菜单内选择；预设为内置常用模板。
