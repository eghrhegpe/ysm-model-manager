# 批量重命名

## 它能做什么

对仓库中多个文件一键批量重命名：支持「解析格式」（统一补全作者/作品）与「查找替换」（含正则）两种模式，内置 5 个常用预设，重命名前可逐一预览「原名 → 新名」。

## 打开方式

- 在「模型仓库」勾选多个文件 → 右键「✂️ 批量重命名...」
- 右键文件夹 →「📝 批量重命名…」（对文件夹内文件生效）

## 操作步骤

### 1. 选择模式

弹窗标题显示目录路径与「N 个文件 · M 个变更」，模式下拉二选一：

| 模式 | 字段 | 适用 |
|------|------|------|
| 📋 解析格式 | 作者 / 作品（均「留空不变」，回车生效） | 给一批文件统一补全 `[作者]【作品】` 前缀 |
| 🔍 查找替换 | 查找内容 / 替换为（留空为删除）/「正则」复选框 | 去除年份、替换括号等规则化整理 |

### 2. 使用预设

「📋 预设」按钮展开/收起内置模板（均为正则规则）：

| 预设 | 效果 |
|------|------|
| ❌ 去除年份 | 删除 `(2024-05)` 这类年月括号 |
| ❌ 去除版本 -v2 | 删除文件名中的 `-v2` 等版本段 |
| 【】→ [] 括号 | `【作品】` 改为 `[作品]` |
| 📛 拍平为 作者-作品 | `[作者]【作品】` 合并为 `作者-作品` |
| 🔗 空格 → 下划线 | 所有空白字符替换为 `_` |

### 3. 预览与应用

- 预览区列出每个文件的「原名 → 新名」对照，可用「全选」复选框控制参与范围
- 点「✅ 应用重命名 (Enter)」执行（执行中按钮变「⏳ 执行中...」），完成 toast「✅ 批量重命名完成：N 成功」
- 无变更时提示「没有需要重命名的文件」；正则非法时提示「⚠️ 正则表达式无效，已保持原名」

## 常见问题

**Q：重命名后模型找不到？**
A：重命名只改文件名，模型内容不变；文件树会刷新为新名称。若之前按名称搜索，请用新名称。

**Q：单个文件怎么重命名？**
A：右键单文件 →「✂️ 重命名」，打开命名表单逐字段修改（作者/品牌/角色/变体/年月），见 [导入队列与命名表单](./import-queue.md) 的命名规则。

**Q：重命名失败会怎样？**
A：逐文件执行，失败项保留原名，成功项照常生效，完成提示中的计数反映实际结果。
