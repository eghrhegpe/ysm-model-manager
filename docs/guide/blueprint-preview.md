# 整合包蓝图预览

在文件树中选中蓝图文件（`.litematic` / `.schematic` / `.schem` / `.nbt`），右侧预览面板显示三个页签：

- **📋 详情**：蓝图元信息；
- **🧱 材料列表**：所需方块统计；
- **🎨 3D**：体素三维预览。

## 详情页签

**Litematic（.litematic）**：

- 名称、作者、创建时间、保存时间；
- 格式版本、描述；
- 区域数量；
- 内嵌预览图（如文件自带，直接显示缩略图）。

**所有格式公共信息**：

- 非空气方块数；
- 总体积（长 × 宽 × 高）；
- 包围盒尺寸。

## 材料列表页签

列出蓝图内所有方块及数量，方块名称显示为中文（如「平滑石砖」「橡木台阶」）。可用于开工前核对材料储备是否齐全。

## 体素 3D 预览页签

- **分层查看**：沿 Y / X / Z 轴选择「全部」「单层」或指定范围，逐层观察结构；
- **显示上限**：方块数超过 200,000 时仅显示部分内容，并提示「⚠️ 方块数量超过上限（200,000），仅显示部分内容」。

## 常见问题

- **预览打不开 / 信息为空**：文件可能损坏或格式不受支持；
- **材料列表为空**：蓝图中无非空气方块，或解析失败（检查文件完整性）；
- **3D 只显示一部分**：超过显示上限属预期行为，不影响实际文件内容。

## 相关功能

- 《3D 与 2D 预览》——模型文件的预览
- 《仓库页面总览》——蓝图文件的存放位置（pack 子目录）
