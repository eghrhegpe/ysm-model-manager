# 创作者频道

## 它能做什么

浏览 YSM 模型创作者列表与在线资源：站点快速跳转、预设搜索、87+ 创作者数据库，以及应用内嵌浏览器。

## 打开方式

主界面左侧导航栏 →「🎨 创作者频道」。

## 操作步骤

### 1. 站点管理

B站、爱发电等平台快速跳转，一键进入创作者主页。

### 2. 预设搜索

一键搜索「YSM 免费模型」「YSM 模型分享」等预设关键词，快速找到资源。

### 3. 创作者数据库

87+ 位 YSM 创作者列表，按平台分类（bilibili / afdian / github）。

### 4. 内嵌浏览器

在应用内直接浏览网页，无需切换窗口。

## 常见问题

**Q：如何添加新的创作者到数据库？**
A：创作者信息存储在仓库根目录的 `creators.json`。可手动编辑，或在创作者频道使用导入功能。格式示例：

```json
{
  "name": "创作者名称",
  "desc": "简介",
  "type": "bilibili"
}
```

`type` 可选值：`bilibili`、`afdian`、`github`，可用分号组合如 `bilibili;afdian`。
