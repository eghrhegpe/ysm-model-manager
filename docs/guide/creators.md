# 创作者频道

创作者频道收录了社区维护的创作者名单（当前 232 位），可以一键跳转到每位创作者的平台主页。

## 打开方式

导航栏点击「🎨 创作者频道」。页面左侧是创作者列表，右侧是预览/浏览器区域。

## 浏览与搜索

- **搜索框**：按创作者名称过滤；
- **卡片信息**：每位创作者显示名称、简介、身份标签——创作者 / 官方 / VUP / OC / 仓库，以及收录的平台图标（共支持 10 个站点：哔哩哔哩、爱发电、YouTube、X(Twitter)、蓝狸、Fanbox、Ko-fi、Gumroad、Booth、GitHub）；
- **⭐ 收藏**：点击卡片上的星标收藏，收藏的创作者排在前面；
- **键盘操作**：↑ ↓ 上下选择创作者，← → 切换该创作者的平台，Enter 打开当前平台。

## 打开创作者主页

- **↗ 外部链接**：用系统默认浏览器打开平台主页；
- **🔍 内嵌浏览**：在应用内打开只读浏览窗口。内嵌窗口顶部只有「← 返回」「↗ 浏览器打开」和只读地址栏（不能输入网址）——部分站点的登录、交互功能可能受限，需要交互时请点「↗ 浏览器打开」；
- **🌐 更新配置**：从社区源拉取最新的创作者名单。

## 常见问题

- **名单不是最新的**：点「🌐 更新配置」拉取最新数据；
- **内嵌页面打不开 / 空白**：该站点不允许被内嵌加载（安全策略），改用外部浏览器打开；
- **想补充创作者**：名单来自社区维护的配置文件（`creators.json`），向社区仓库提交更新即可。
