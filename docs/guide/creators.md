# 创作者频道

创作者频道收录社区维护的创作者名单，按创作平台分组展示。可一键跳转到创作者的平台主页，也可直接按作者名在各平台搜索其作品。

## 打开方式

导航栏点击「🎨 创作者频道」。页面顶部是**平台标签栏**，点击切换平台；下方是该平台的创作者卡片网格。

平台标签由站点配置派生，随配置更新增减，当前包括：B站、爱发电、GitHub、模之屋、Bowlroll、VRoid、NicoNico 3D、DeviantArt、BOOTH、CMS蓝图站。

## 浏览与搜索

- **搜索框**：在**当前平台内**按创作者名称或简介过滤，筛选结果计数显示为「可见/总数」；无匹配时给出「清除筛选」出口；
- **身份筛选行**：只列出该平台**实际存在**的身份（创作者 / 官方 / VUP / OC / 仓库）+「全部」，不会出现点了必然零结果的按钮；
- **卡片信息**：名称、简介、身份标签、收录的平台徽章；
- **📁 本地徽章**：该创作者的作品你本地已有下载时出现，点击跳到仓库页搜索该作者名下的模型；
- **🔍 搜索按钮**：该平台支持站内搜索时出现（如 CMS蓝图站没有搜索能力则不出），免进详情直接按创作者名在该平台搜索；
- **⭐ 收藏**：点击卡片星标收藏，收藏的创作者排在最前（取消收藏后回到按本地模型数排序的位次）；
- **键盘操作**：`↑` `↓` `←` `→` 在创作者卡片间移动焦点（末尾自动回绕），`Enter` / `Space` 打开该创作者的详情浮层。全表见 [快捷键](./keyboard-shortcuts.md)。

## 详情浮层

点击卡片打开，包含头像与名称、平台徽章、身份行、简介，以及两个出口：

- **简介**：形如「模型、捏人、皮肤」的标签串会拆成标签展示，其余按全文显示（不会截断）；
- **查看本地模型**：跳到仓库页并按该作者名搜索；
- **搜索更多模型**：在该创作平台按作者名搜索。

## 打开创作平台

预设搜索词按钮、卡片上的 🔍 按钮、浮层的「搜索更多模型」都会按**当前浏览模式**打开站点。模式开关在「网页搜索词」标题栏右侧：

- **外链**：用系统默认浏览器打开；
- **内嵌**：在应用内打开只读浏览窗口——顶部只有「← 返回」「↗ 浏览器打开」和只读地址栏（不能输入网址）。部分站点的登录与交互功能受限，需要交互时改用「外链」；
- **窗口**：以独立窗口打开。

切换模式即时生效，点谁就按当前模式打开谁。

## 编辑创作者名单

点标题栏「编辑」进入编辑态：

- 修改名称、简介；点击平台标签勾选所属平台（可多选）；选择身份（创作者 / 官方 / VUP / OC / 仓库）；
- 拖拽卡片调整顺序；**➕ 新增** 与 **删除** 单条；**保存** 或 **取消**；
- 有未保存修改时点「取消」会先弹确认，防止误丢；
- 也可把创作者 JSON 文件直接拖到编辑区的虚线框导入。

## 更新配置

标题栏「🌐 更新配置」从社区源拉取最新的创作者名单与站点配置并入本地。并入**只补空缺**（描述、身份为空时补上；所属平台分段合并），不会覆盖你已填写的内容。

## 常见问题

- **名单不是最新的**：点「🌐 更新配置」；
- **内嵌页面打不开 / 空白**：该站点不允许被内嵌加载（安全策略），改用「外链」打开；
- **想补充创作者**：在界面内点「编辑」即可新增；名单的公共部分来自社区维护的 `creators.json`，向社区仓库提交更新可让所有用户受益。
