# 诊断与去重

## 它能做什么

维护仓库健康：操作日志追踪所有安装/导入/删除记录，SHA256 检测重复文件，扫描同名文件跨整合包冲突。

## 打开方式

主界面左侧导航栏 →「🛠️ 诊断与冲突」。

## 操作步骤

### 1. 操作日志

所有安装、导入、删除操作的历史记录，失败原因分行显示——排查「为什么没装上」的第一入口。

### 2. 模型去重

按 SHA256 检测仓库中的重复文件，逐组选择保留哪个副本，其余移入回收站（可恢复）。

### 3. 冲突检测

扫描同名文件存在于多个整合包中的情况，提前发现潜在覆盖问题。

## 常见问题

**Q：误删了去重副本？**
A：去重操作把副本移入回收站而非直接删除，可在设置页回收站恢复。

**Q：日志在哪里找？**
A：程序会在桌面生成 `ysm-debug.log` 文件，记录运行调试信息；遇到问题可查看此文件或连同操作日志一起反馈。
