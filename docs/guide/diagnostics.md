# 诊断与去重

## 它能做什么

「🛠️ 诊断与冲突」页面提供三类工具：

- **📋 操作日志**：追踪所有安装/导入/删除等操作的记录，排查「为什么没装上」的第一入口；
- **🔄 同步冲突**：逐文件比较某个整合包实例与仓库的内容差异（SHA256 实证），并支持三策略解决（用远端 / 用本地 / 手动）；
- **🏥 仓库健康审计**：一键体检当前资源类型仓库——完整性、纹理缓存命中率、重复组与可回收空间、健康分与改进建议。

> 模型去重、回收站、资历最深这三个功能在**仓库页的对应 tab** 中，不在本页（见《模型去重》《回收站》《仓库元老》）。
> 原「⚡ 冲突检测」（跨实例同名文件扫描）已下线：它与「同步冲突」用户视角重叠、判定只到「同名聚合」却不含解决动作，覆盖面由同步冲突与去重两处兜底。

## 打开方式

主界面左侧导航栏 →「🛠️ 诊断与冲突」。顶部 tab 在各工具间切换，默认显示操作日志。

## 操作步骤

### 1. 操作日志

- 记录最近 500 条操作，每条带 ✅ 成功 / ❌ 失败 / ⏭️ 跳过 状态标记；
- **筛选**：按状态过滤（只看失败项最快定位问题）；
- **搜索**：按文件名/关键词搜索；
- **🔄 刷新**：重新读取日志；**🗑️ 清空**：清空日志记录；
- 失败条目会分行显示具体原因，按提示处理即可。

### 2. 同步冲突

1. 切换到「同步冲突」tab；
2. 选择资源类型与整合包实例，点「扫描同步冲突」；
3. 列出两端内容不一致的文件（附大小对比与按修改时间推断的建议策略）；
4. 选定策略（强制使用远端版本 / 强制使用本地版本 / 手动解决）点「解决冲突」，界面自动复扫确认结果。

### 3. 仓库健康审计

1. 切换到「仓库健康审计」tab，点「开始体检」；
2. 报告给出健康分（0–100）、完整性、纹理缓存命中率、去重组数与可回收空间；
3. 警告区按当前资源类型给精准建议；去重建议可转到仓库页「🔗 去重」tab 执行。

## 常见问题

**Q：日志太多找不到想要的那条？**
A：先用筛选选「❌ 失败」，再用搜索框输入文件名关键词。

**Q：清空日志会影响功能吗？**
A：不会，日志只是历史记录，清空后新操作照常记录。

**Q：同步冲突和仓库体检是一回事吗？**
A：不是。同步冲突比对的是「实例 ↔ 仓库」两端同一文件内容是否分叉，且可一键解决；体检看的是「仓库自身」的完整性、缓存与重复情况，只出报告不改文件。
