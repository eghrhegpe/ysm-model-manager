# 诊断与去重

## 它能做什么

「🛠️ 诊断与冲突」页面提供两个工具：

- **📋 操作日志**：追踪所有安装/导入/删除等操作的记录，排查「为什么没装上」的第一入口；
- **⚡ 冲突检测**：扫描同名文件存在于多个整合包中的情况，提前发现潜在覆盖问题。

> 模型去重、回收站、资历最深这三个功能在**仓库页的对应 tab** 中，不在本页（见《模型去重》《回收站》《仓库元老》）。

## 打开方式

主界面左侧导航栏 →「🛠️ 诊断与冲突」。左栏可在两个工具间切换，默认显示操作日志。

## 操作步骤

### 1. 操作日志

- 记录最近 500 条操作，每条带 ✅ 成功 / ❌ 失败 / ⏭️ 跳过 状态标记；
- **筛选**：按状态过滤（只看失败项最快定位问题）；
- **搜索**：按文件名/关键词搜索；
- **🔄 刷新**：重新读取日志；**🗑️ 清空**：清空日志记录；
- 失败条目会分行显示具体原因，按提示处理即可。

### 2. 冲突检测

1. 切换到「⚡ 冲突检测」；
2. 点「⚡ 开始扫描」；
3. 扫描所有整合包中的同名文件，列出冲突组（最多显示前 50 条）；
4. 按提示决定保留哪个整合包中的版本（结合《整合包同步》的推送/拉取处理）。

## 常见问题

**Q：日志太多找不到想要的那条？**
A：先用筛选选「❌ 失败」，再用搜索框输入文件名关键词。

**Q：清空日志会影响功能吗？**
A：不会，日志只是历史记录，清空后新操作照常记录。

**Q：冲突检测扫出很多同名文件，都要处理吗？**
A：不一定。只有当你同时启用多个含同名文件的整合包时才可能互相覆盖；只启用一个整合包时无影响。
