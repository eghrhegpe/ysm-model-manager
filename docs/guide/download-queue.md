# 下载队列

创意工坊的下载任务统一进入下载队列管理，可查看进度、取消任务。

## 打开方式

创意工坊页右上角的下载队列入口，显示当前排队/下载中的任务数量。

## 队列机制

- **串行下载**：任务逐个执行，避免并发请求被 GitHub 限速；
- **进度显示**：每个任务实时显示百分比进度条；
- **完成/失败**：成功后自动从活动列表移除，失败进入错误列表（底部汇总提示「⚠️ N 个文件下载失败」，最多展开前 5 条明细）；
- **取消**：进行中的任务可单独取消。

## 可靠性设计

- **三镜像源回退**：每个文件依次尝试 GitHub raw、jsDelivr、GitHub API 三个源，一个失败自动换下一个（这是没有断点续传的替代方案——重新下载整个文件）；
- **99% 卡死保护**：进度到 99% 但服务器未返回完整长度时，界面锁定 99% 并在约 2 秒后转为转圈等待动画，避免看起来「卡死」；
- **超时保护**：单个请求 300 秒超时自动放弃；
- **切换页面不丢任务**：队列状态持续保留，离开创意工坊再回来进度仍在。

## 常见问题

- **下载速度很慢**：取决于三个镜像源的连通质量，晚高峰可能变慢；
- **任务一直 99%**：正在等服务器收尾，2 秒后会转为等待动画，超时后自动判失败；
- **失败了怎么办**：重新在创意工坊点击该文件的下载即可（文件已存在时会提示跳过或覆盖）；
- **队列里的任务删不掉**：完成/失败的任务会自动清理，无需手动管理。
