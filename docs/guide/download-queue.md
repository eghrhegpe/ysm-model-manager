# 下载队列

## 它能做什么

管理「创意工坊」发起的批量模型下载：任务排队、进度条实时更新、失败项分类展示，页面切换不中断（模块级持久层）。

## 打开方式

在「🧩 创意工坊」选择模型后点击下载，下载队列自动开始工作；队列状态可在界面查看。

## 操作步骤

### 1. 任务入队

每个下载任务包含：下载地址（url）、保存目录（saveDir）、文件名（name）与大小（size）。批量选择多个模型时任务依次入队。

### 2. 状态流转

| 状态 | 含义 |
|------|------|
| `idle` | 排队等待 |
| `downloading` | 正在下载（显示进度条） |
| `done` | 完成 |
| `cancelled` | 已取消 |

### 3. 进度显示

- 队列显示总任务数（total）与剩余数（remaining）
- 当前文件（currentFile）高亮
- 进度条实时更新（已下载 / 总大小）

### 4. 错误处理

失败任务进入错误列表（errorList），显示文件名与失败原因；其它任务继续执行，互不影响。

## 常见问题

**Q：下载中断了会怎样？**
A：后端下载器（`go/download`）支持重试与断点续传；队列模块级持久，切页不丢状态。

**Q：下载失败怎么排查？**
A：查看队列错误列表中的失败原因；网络/代理问题见 [创意工坊](./workshop.md) 常见问题。
