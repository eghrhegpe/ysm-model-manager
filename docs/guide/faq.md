# 常见问题（FAQ）

## 它能做什么

汇总安装、配置、同步、导入、预览等高频问题与对应的故障排查路径。

## 安装与启动

**Q：下载了 exe 但打不开 / 闪退？**
A：① 缺 WebView2 运行时（从 [Microsoft 官网](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 下载）；② 杀毒软件误报，加入白名单；③ 程序目录路径含中文/空格。

**Q：启动后页面空白？**
A：检查 WebView2 是否安装；尝试以管理员身份运行。

## 模型与整合包

**Q：模型列表为空？**
A：确认仓库路径配置正确，目录下有 `.ysm` / `.zip` / `.7z` 文件（[首次配置](./first-setup.md)）。

**Q：整合包列表为空？**
A：确认游戏根目录配置正确，目录下有 `versions` 文件夹。

**Q：模型启用/禁用了，游戏中没变化？**
A：① 确保整合包安装 YSM 模组（1.0.0+）；② F3+T 重载资源包；③ 硬链接即时同步，复制模式需重新安装（[整合包同步](./pack-sync.md)）。

**Q：「安装」按钮卡在导入中？**
A：检查整合包 `custom` 目录是否被游戏锁定，关掉游戏重试。

## 导入与预览

**Q：导入时提示「未检测到模型文件」？**
A：确认后缀为 `.ysm` / `.zip` / `.7z`；zip 需含 `minecraft:geometry` 格式 JSON；确定来源安全时才尝试跳过文件头校验。

**Q：3D 预览不显示？**
A：部分高面数模型（>2000 cubes）可能卡顿，稍等片刻。

## 其它

**Q：日志在哪里？**
A：桌面 `ysm-debug.log` 文件。

**Q：如何备份配置？**
A：备份与 exe 同目录的 `ysm_config.json`（[设置](./settings.md)）。

**Q：如何更新程序？**
A：见 [版本更新](./update.md)。

## 故障排查表

| 症状 | 检查项 |
|------|--------|
| 启动后页面空白 | WebView2 安装；管理员运行 |
| 模型列表为空 | 仓库路径 + `.ysm`/`.zip`/`.7z` 文件存在 |
| 按钮点击无反应 | 重启；刚更新过则确认旧进程完全退出 |
| 整合包列表为空 | 游戏根目录 + `versions` 文件夹 |
| 安装卡在导入中 | 整合包 `custom` 目录被游戏锁定 |
| 3D 预览不显示 | 高面数模型卡顿，稍等 |

> 未能解决？到 [GitHub Issues](https://github.com/eghrhegpe/ysm-model-manager/issues) 反馈，附上日志文件与操作截图。
