# 常见问题（FAQ）

## 它能做什么

汇总安装、配置、同步、导入、预览等高频问题与对应的故障排查路径。

## 安装与启动

**Q：下载了 exe 但打不开 / 闪退？**
A：① 缺 WebView2 运行时（从 [Microsoft 官网](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 下载）；② 杀毒软件误报，加入白名单；③ 程序目录路径含中文/空格时尝试换位置。

**Q：启动后页面空白？**
A：检查 WebView2 是否安装；尝试以管理员身份运行。

## 配置与数据

**Q：配置文件在哪里？**
A：`%APPDATA%\YSM-Model-Manager\ysm_config.json`（资源管理器地址栏粘贴 `%APPDATA%\YSM-Model-Manager` 即可打开）。导入日志在同目录的 `ysm-import-logs.json`。

**Q：如何备份？**
A：备份上述 `%APPDATA%\YSM-Model-Manager` 目录 + 仓库本体即可，见 [备份与迁移](./backup-migration.md)。

## 模型与整合包

**Q：模型列表为空？**
A：确认仓库路径配置正确，目录下有 `.ysm` / `.zip` / `.7z` 等受支持的文件（[首次配置](./first-setup.md)）。

**Q：整合包列表为空？**
A：确认游戏根目录配置正确，目录下有 `versions` 文件夹。

**Q：模型启用/禁用了，游戏中没变化？**
A：① 确保整合包安装 YSM 模组（1.0.0+）；② 游戏内 F3+T 重载资源包；③ 硬链接模式即时同步，复制模式需重新推送（[整合包同步](./pack-sync.md)）。

**Q：推送时提示目录被占用？**
A：关掉游戏（或占用该目录的程序）再重试。

## 导入与删除

**Q：导入时提示「未检测到模型文件」？**
A：确认后缀受支持（`.ysm` / `.zip` 等）；zip 需含 YSM 格式的模型 JSON。

**Q：删除的文件去哪了？**
A：右键菜单的删除会移入 [回收站](./recycle-bin.md)（仓库页「♻️ 回收站」tab，可恢复）。**注意：键盘 Delete 键是硬删除，不进回收站、不可恢复**。

**Q：回收站在哪里？**
A：仓库页的「♻️ 回收站」tab（不在设置页）。

## 预览与社区

**Q：3D 预览空白 / 不显示？**
A：需要本机支持 WebGL。更新显卡驱动后重试；模型过大时会较慢，稍等片刻。

**Q：创意工坊下载很慢 / 失败？**
A：下载走三镜像源（GitHub raw / jsDelivr / GitHub API）自动回退，全部失败说明网络受限，稍后重试或科学上网。见 [下载队列](./download-queue.md)。

**Q：内嵌浏览器打不开创作者主页？**
A：部分站点禁止被内嵌加载（安全策略），点「↗ 浏览器打开」改用外部浏览器。见 [创作者频道](./creators.md)。

## 同步与链接模式

**Q：硬链接跨分区报错？**
A：硬链接不支持跨分区，程序不会自动降级——把仓库和游戏目录放到同一分区，或改用复制模式（[首次配置](./first-setup.md)）。

## 故障排查表

| 症状 | 检查项 |
|------|--------|
| 启动后页面空白 | WebView2 安装；管理员运行 |
| 模型列表为空 | 仓库路径 + 受支持的文件类型存在 |
| 按钮点击无反应 | 重启程序；刚更新过则确认旧进程完全退出 |
| 整合包列表为空 | 游戏根目录 + `versions` 文件夹 |
| 推送失败 | 整合包目录被游戏占用，关游戏重试 |
| 3D 预览空白 | WebGL 支持 / 显卡驱动 |
| 找不到删除的文件 | 仓库页「♻️ 回收站」tab（Delete 键硬删除除外） |

> 未能解决？到 GitHub Issues 反馈，附上操作日志截图（诊断与冲突 → 操作日志）。
