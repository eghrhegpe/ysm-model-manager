# 首次配置

## 它能做什么

配置程序运行必需的三件事：**文件存储路径**（模型仓库）、**游戏根目录**（.minecraft）与**链接模式**（推送到整合包的安装方式）。前两项决定程序去哪找文件，第三项决定模型怎么进游戏。

## 打开方式

启动程序后首次进入会自动弹出设置页面；之后点击左侧导航「⚙️ 设置」→「⚙️ 基础设置」可随时修改。

## 操作步骤

### 1. 配置文件存储路径（模型仓库）

所有资源文件统一存放于此，按类型分子目录。点击路径文字本身即弹出目录选择对话框（没有单独的浏览按钮），成功后提示「✅ 路径已更新」。

- 首次启动会自动在该目录下创建 `ysm` / `resourcepacks` / `shaderpacks` / `schematics` / `mmd` / `vrchat` 六个子目录
- 点「📂 展开 ▸」可为每种资源类型单独指定路径（留空则使用统一存储路径），用「↩️ 默认」恢复

> ⚠️ 建议文件存储路径与游戏根目录在**同一分区**：硬链接模式要求同分区，跨分区推送会报错「仓库与游戏目录在不同分区，不支持硬链接」。

### 2. 配置游戏根目录（.minecraft 路径）

点击「🎮 游戏根目录」旁的「🔍 自动搜索」，程序会扫描常见位置：

- C 盘 ~ Z 盘根目录的 `.minecraft` 与各启动器目录（PCL2、PCL、HMCL、BakaXL、MC、Minecraft、Games、PrismLauncher、MultiMC、PolyMC）
- `%APPDATA%\.minecraft`、`%ProgramFiles%\Minecraft`、`D:\Games` 等常见游戏目录
- exe 同目录及其上一级的 `.minecraft`

识别依据是目录中的特征文件：`versions`、`assets`、`launcher_profiles.json`、`mods`、`config`、`prismlauncher.cfg`；PrismLauncher 的 `instances` 布局也能识别。

- 搜到 1 个结果直接采用；搜到多个弹出「🔍 选择游戏目录」让你挑；搜不到提示「未找到已存在的游戏目录，请手动选择」
- 首次启动时若此处为空，程序会自动把扫描到的第一个游戏目录填上

常见启动器默认路径参考：

| 启动器 | 默认路径 |
|--------|---------|
| PCL2 | `C:\PCL2\.minecraft` |
| HMCL / 官方启动器 | `C:\Users\你的用户名\.minecraft` |
| PrismLauncher | `%APPDATA%\PrismLauncher\instances\<实例>\.minecraft` |

> 💡 游戏根目录只用于整合包同步，不影响文件存储位置——没配它也能正常管理仓库。

### 3. 选择链接模式

三种安装方式，在设置页的下拉菜单中切换：

| 模式 | 说明 | 适用 |
|------|------|------|
| **🔗 硬链接** | ✅ 推荐：省磁盘空间，支持实时开关模型 | 📌 需与游戏同分区 |
| **📋 复制** | 每个整合包独立占用磁盘空间，最兼容 | 跨分区 / 保守选择 |
| **🔗 符号链接** | ❌ 不推荐：权限不足时文件被挂起 | 需要管理员权限，YSM 兼容性差 |

- **切换下拉即保存**，并自动对所有整合包执行重新链接（完成提示「🔄 已重新链接 N 个文件」）
- 「🔄 重新应用」按钮可手动重链全部整合包
- 硬链接模式下，仓库启用/禁用模型会即时同步到整合包；复制模式的文件互相独立

**注意**：跨分区时硬链接**不会自动降级**——推送操作会直接报错并提示切换复制模式。

## 常见问题

**Q：手动选的目录程序不认？**
A：需要选择包含 `versions/` 或 `instances/` 等子目录的游戏目录；若选的是父目录，程序会尝试识别其下的 `.minecraft`，仍失败时请精确选择 `.minecraft` 文件夹本身。

**Q：跨分区能用硬链接吗？**
A：不能。硬链接是文件系统特性，无法跨分区；程序会报错并建议切换到复制模式，不会自动降级。

**Q：符号链接为什么需要管理员权限？**
A：Windows 创建符号链接默认需要管理员或开发者模式；权限不足时创建失败，文件会被挂起，所以不推荐。
