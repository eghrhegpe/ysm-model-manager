# 模型导入

## 它能做什么

把 YSM 模型文件加入仓库：支持拖拽导入、文件夹导入，`.ysm` / `ysm.json` 自动进入命名表单，`.zip` / `.7z` 自动检测内容类型。

## 打开方式

- **拖拽**：把文件/文件夹直接拖入主窗口（出现「放开以导入模型」浮层时松手）
- 支持扩展名：`.ysm` / `.ysm.json` / `.zip` / `.7z` 及仓库注册的其它资源类型

## 操作步骤

### 1. 直接导入

- `.ysm` 文件 → 拖入后进入命名表单（可为模型命名）
- 其它已注册扩展名 → 直接导入仓库，无需确认

### 2. zip / 7z 智能识别

拖入 `.zip` / `.7z` 时，程序自动调用 Go 端 `DetectZipType` 检测压缩包内容：

- 内容是 YSM 模型 → 进入命名表单
- 其它类型 → 按对应资源类型导入

### 3. 批量导入

- 一次可拖入最多 50 个文件
- 单个文件上限 100MB（MMD/VRC 大文件可达 50MB+）
- 导入队列显示进度，失败项分行展示原因

## 常见问题

**Q：拖入后没反应？**
A：确认文件扩展名受支持；`.zip` 需内部包含 `minecraft:geometry` 格式的 JSON 才会被识别为 YSM。

**Q：提示「未检测到模型文件」？**
A：① 确认后缀是 `.ysm` / `.zip` / `.7z`；② zip 内容需含 YSM 格式 JSON；③ 仅当你确定文件来源安全时可尝试跳过文件头校验。

**Q：导入后游戏里看不到？**
A：模型需在「模型仓库」启用，并已安装到目标整合包（见 [整合包同步](./pack-sync.md)）。
