# 模型导入

## 它能做什么

把资源文件加入仓库：拖拽导入、点击选择文件/文件夹导入。`.ysm` 会进入命名表单让你规范命名，`.zip` / `.7z` 自动检测内容类型（YSM 模型 / 资源包 / 光影包），其它已注册类型直接入库。

## 打开方式

三个入口：

1. **全局拖拽**：把文件/文件夹直接拖入「📚 模型仓库」页面任意位置，出现「📥 放开以导入模型」浮层时松手（浮层下方列出全部支持的扩展名）
2. **导入 tab**：仓库页「📥 导入」tab 的拖拽区，点击选择文件、`Ctrl`+点击选择文件夹，或直接把文件拖进拖拽区
3. **文件树菜单**：文件树工具栏「⋮ 更多 ▾」→「导入文件 / 📁 导入文件夹」（适用于资源包、光影包、蓝图等类型）

支持的扩展名：`.ysm` / `.json`（限文件名 `ysm.json`）/ `.zip` / `.7z` / `.pmx` / `.pmd` / `.vrca` / `.vrm` / `.nbt` / `.schematic` / `.litematic`。

## 操作步骤

### 1. 导入分流规则

| 文件 | 去向 |
|------|------|
| `.ysm` | 始终进入命名表单（见 [导入队列与命名表单](./import-queue.md)） |
| 名为 `ysm.json` 的文件 | 进入命名表单 |
| `.zip` | 自动检测内容：含 `pack.mcmeta` → 资源包；含 `shaders/` → 光影包；含 `ysm.json` 或 `models/` → YSM 进表单；无法识别时按 YSM 处理 |
| `.7z` | 一律进入命名表单（按 YSM 处理） |
| 其它已注册扩展名 | 直接导入对应类型仓库，无需确认 |

### 2. 数量与大小限制

| 限制 | 值 | 说明 |
|------|----|------|
| 全局拖拽单次文件数 | 50 | 超出提示「⚠️ 单次导入文件过多（N 个），请分批处理」 |
| 全局拖拽单文件大小 | 100MB | 超出提示直接放入仓库文件夹 |
| 程序导入上限 | 500MB | 超出报错「文件大小超过 500MB 限制」 |

### 3. 同名与覆盖

- 导入时若仓库已有同名文件，弹出「文件已存在」确认框，可选「覆盖」或取消
- 导入队列内会自动按文件名去重，重复拖入不会产生两份任务

### 4. 文件头校验

导入 `.zip` / `.ysm` / `.7z` 时会检查文件头魔数；不匹配**不会拦截导入**，只记录一条警告日志（「文件头不匹配标准 ZIP 格式…已导入」），可在「🛠️ 诊断与冲突」的操作日志中查看。

## 常见问题

**Q：拖入后没反应？**
A：确认文件扩展名受支持（浮层变红并显示「⛔ 未检测到模型文件」说明拖入内容里没有支持的文件）；拖拽导入仅在模型仓库页生效。

**Q：zip 被当成了 YSM？**
A：压缩包内没有 `pack.mcmeta`、`shaders/`、`ysm.json`、`models/` 等特征内容时默认按 YSM 处理。资源包请确认包内有 `pack.mcmeta`。

**Q：导入后游戏里看不到？**
A：模型需在仓库启用（无 `.ban` 后缀），并已推送到目标整合包（见 [整合包同步](./pack-sync.md)）。

**Q：导入的文件夹会保留目录结构吗？**
A：通过「📥 导入」tab 拖拽区拖入的文件夹会保留相对子目录；全局拖拽与文件选择器导入则平铺到类型仓库根目录。
