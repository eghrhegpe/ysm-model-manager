# 导入队列与命名表单

## 它能做什么

2026-08-05 起导入流程已简化：拖拽或选择文件后直接执行导入，不再经过独立的「导入 tab」工作台。绝大多数文件静默入库（保留原文件名），仅 `ysm.json` 单文件会弹出命名表单让你规范命名。

## 导入流程

### 全局拖拽

把文件/文件夹直接拖入「📚 模型仓库」页面任意位置，出现「📥 放开以导入模型」浮层时松手。

- 单文件：直接导入，保留原文件名
- 文件夹：整组导入，保留相对子目录结构（组内至少含 1 个支持文件才导入）

### 文件树菜单导入

文件树工具栏「⋮ 更多 ▾」→「导入文件 / 📁 导入文件夹」，适用于资源包、光影包、蓝图等类型。

## 命名表单

### 触发条件

仅以下文件进入命名表单（提示「导入仓库前，先重命名一下吧：」）：

| 文件 | 是否进表单 |
|------|-----------|
| `.ysm` | ❌ 直接导入，保留原名 |
| `ysm.json`（单文件） | ✅ 进入命名表单 |
| `.zip` / `.7z` | ❌ 直接导入，后端自动路由类型 |
| 其它已注册扩展名 | ❌ 直接导入 |

> 2026-08-05 改造前 `.ysm` 强制进入命名表单；现改为静默导入，仅 `ysm.json` 保留表单提示。

### 表单字段

| 字段 | 说明 |
|------|------|
| 作者 | 必填（空则按原文件名处理） |
| 作品品牌 | 空则记为「未知」 |
| 角色名 | 必填 |
| 变体 | 可选 |
| 年月 | 勾选「当天」时自动填当前年月 |

- 表单会先从原文件名自动解析出作者（`[作者]`）、作品（`【作品】`/`《作品》`）与年月作为预填
- 勾选「读取作者」可从模型文件头提取作者信息自动填充
- 下方实时预览最终文件名，格式为 `[作者]【作品】角色-变体 (日期).扩展名`
- 仓库已有同名文件时显示 ⚠️ 冲突提示
- 点「📥 导入」后还会弹出「✂️ 重命名模型」确认框（可最后微调），确认后入库；「✕」取消

### 命名规则

- 作者、角色名不能为空
- 文件名不能包含 `< > : " / \ | ? *` 等字符
- 完整文件名不超过 255 字符

## 同名与覆盖

导入遇到同名文件时弹出「文件已存在」确认框：选择「覆盖」走覆盖导入（提示「✅ 已覆盖」），或取消保留原文件。

## 常见问题

**Q：`.ysm` 文件还需要命名吗？**
A：不需要。2026-08-05 起 `.ysm` 直接导入保留原名，仅 `ysm.json` 单文件进入命名表单。

**Q：zip 被判定为非 YSM？**
A：内容检测按压缩包条目名判断——`pack.mcmeta` 归资源包、`shaders/` 归光影包、`ysm.json` 或 `models/` 归 YSM，都不匹配时默认按 YSM 直接导入。

**Q：导入卡住了？**
A：导入是异步执行的，toast 提示「✅ 已导入: 文件名」或「❌ 导入失败: 原因」，文件树会自动刷新。若长时间无响应，重启程序。
