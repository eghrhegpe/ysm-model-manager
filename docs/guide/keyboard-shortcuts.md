# 键盘快捷键

## 它能做什么

常用操作的键盘直达：搜索聚焦、删除、弹窗确认、3D/体素预览导航与创作者卡片选择。

## 操作步骤

### 1. 仓库页

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+F` / `Cmd+F` | 聚焦并全选搜索框（输入框内也可触发） |
| `Delete` / `Del` | 删除选中的文件（输入框聚焦时不触发，防误删） |

> ⚠️ **Delete 键是硬删除，不进回收站**（只有原生确认框「确定要删除选中的 N 个文件吗？」）。想保留恢复途径，请用右键「♻️ 移入回收站」。

### 2. 弹窗通用

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 确认/提交（重命名、筛选应用、批量重命名等，在输入框内按即可） |
| `Esc` | 取消并关闭弹窗；也是 3D/体素预览的退出键 |

### 3. 3D 预览 / 体素预览

| 按键 | 功能 |
|------|------|
| `W` / `S` / `A` / `D` 或方向键 | 前后左右移动视角 |
| `Space` / `Shift` | 上升 / 下降 |
| `F` | 循环切换 3D 调试可视化（正常 → 枢轴 → 骨架） |
| `Esc` | 退出预览 |

鼠标配合：左键拖拽旋转、滚轮缩放。进入预览时底部会显示 6 秒操作提示条。

### 4. 2D 骨骼图

| 操作 | 功能 |
|------|------|
| 左右拖拽 | 旋转模型 |
| 滚轮 | 缩放（0.2–10 倍） |
| 单击 | 全窗放大预览（Esc 或点遮罩关闭） |

### 5. 创作者卡片

| 按键 | 功能 |
|------|------|
| `↑` / `↓` / `←` / `→` | 在创作者卡片间移动焦点（末尾自动回绕） |
| `Enter` / `Space` | 打开聚焦卡片的详情 |

### 6. 开发者工具

| 快捷键 | 功能 |
|--------|------|
| `F12` / `Ctrl+Shift+I` | 打开开发者工具（仅开发模式生效，正式发行版默认关闭） |

## 常见问题

**Q：Delete 按了没反应？**
A：需先勾选/选中文件（无选中会 toast「请先选中要删除的文件」）；输入框聚焦时快捷键被禁用。

**Q：预览里按键影响了页面？**
A：3D 预览开启时 WASD/方向键/空格会被预览捕获（不会滚动页面）；输入框聚焦时按键不吞，可正常输入。
