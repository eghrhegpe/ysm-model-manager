# 键盘快捷键

## 它能做什么

常用操作的键盘直达：搜索、删除、开发者工具、3D 预览导航等。

## 操作步骤

### 1. 仓库页（app-tree）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+F` / `Cmd+F` | 聚焦搜索框（输入框内可正常响应） |
| `Delete` / `Del` | 删除选中的文件（输入框聚焦时不触发，避免误删） |

### 2. 开发者工具

| 快捷键 | 功能 |
|--------|------|
| `F12` | 打开开发者工具（开发模式） |
| `Ctrl+Shift+I` | 同上 |

### 3. 3D 预览 / 体素预览

| 按键 | 功能 |
|------|------|
| `W` / `A` / `S` / `D` | 体素（Litematic）预览中移动视角 |
| `↑` / `↓` / `←` / `→` | 方向键移动/导航 |
| `Space` | 移动 |
| `Esc` | 关闭弹窗 / 退出预览 |

### 4. 创作者搜索结果

| 按键 | 功能 |
|------|------|
| `↑` / `↓` / `←` / `→` | 在结果卡片间键盘导航（`tabindex` 卡片） |

## 常见问题

**Q：Delete 按了没反应？**
A：需先勾选/选中文件；输入框聚焦时快捷键被禁用（防误删）。

**Q：F12 打不开开发者工具？**
A：仅开发模式（`?dev` 参数或 `_devtools` 标记）生效；正式发行版默认关闭。
