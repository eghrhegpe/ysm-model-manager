# 模型去重

## 它能做什么

基于文件哈希（SHA256）/元数据检测仓库中的重复文件，逐组选择保留哪个副本，其余移入回收站（可恢复）；导入时自动防重复。

## 打开方式

主界面左侧导航栏 →「🛠️ 诊断与冲突」→「模型去重」。

## 操作步骤

### 1. 扫描重复

程序按文件内容哈希分组，相同内容的文件归为一组。

### 2. 逐组选择保留

- 每组重复文件列出全部副本
- 选择要保留的一个（通常保留命名规范 / 路径合理的那个）
- 其余副本移入 [回收站](./recycle-bin.md)，可恢复

### 3. 导入前自动防重复

- `go/dedup` 在导入时基于哈希/元数据检测，避免重复导入相同资源
- 重复检测不影响已安装资源

## 常见问题

**Q：去重会误删吗？**
A：不会直接删除——重复副本移入回收站，可在设置页恢复。

**Q：两个文件同名但内容不同会误判吗？**
A：不会。按内容哈希比对，同名不同内容不视为重复。

**Q：硬链接文件会怎样？**
A：回收站对硬链接采用直接删除链接的策略（不破坏原始数据），见 [回收站](./recycle-bin.md)。
