# 回收站

## 它能做什么

所有删除的模型文件移入 `.recycle` 目录（软删除），可随时恢复；硬链接/符号链接文件按安全策略直接删除，不破坏原始数据。

## 打开方式

「⚙️ 设置」页面底部 →「回收站」区域。

## 操作步骤

### 1. 查看与恢复

- 列表展示已回收文件，可**恢复**回原位置
- 也可**永久删除**（不可恢复，请谨慎）

### 2. 链接文件的安全策略

回收站对不同类型文件采用不同删除策略，避免破坏原始数据：

| 文件类型 | 策略 |
|---------|------|
| 普通文件 | 移入 `.recycle` 目录，可恢复 |
| 硬链接（nlink>1） | 直接删除链接本身，不影响其它链接引用 |
| 符号链接 | 直接删除链接，不影响目标文件 |
| 跨分区 | 复制后删除，不破坏源 |

> 该策略保护的是「整合包 ↔ 仓库」硬链接共享场景：删仓库侧引用不会误伤整合包侧数据。

## 常见问题

**Q：回收站里的文件占空间吗？**
A：普通文件移入 `.recycle` 仍占磁盘空间，确认无用后可永久删除。

**Q：恢复的文件会回到原位吗？**
A：会，恢复操作把文件移回删除前的路径。
