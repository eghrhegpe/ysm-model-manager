# 回收站

## 它能做什么

删除操作的安全网：通过右键「♻️ 移入回收站」删除的文件会移入仓库的 `.recycle` 目录（软删除），随时可恢复或永久删除。硬链接/符号链接文件按安全策略直接删除链接本身，不破坏共享的原始数据。

## 打开方式

「📚 模型仓库」页面顶部 tab →「♻️ 回收站」（跟随当前资源类型子标签显示对应目录的回收内容）。

## 操作步骤

### 1. 查看

列表展示已回收文件：文件名、大小、完整路径（📂 行），顶栏显示计数。点击文件名可预览该文件；「🔄 刷新」重新加载列表。

### 2. 恢复与永久删除

- 「↩️ 恢复」：无确认，直接把文件移回删除前的相对路径（原位已有同名文件时自动加 `(1)` 后缀，不会覆盖），提示「✅ 已恢复」
- 「🗑️ 删除」：确认后永久删除单个文件（「确定永久删除此文件？」）
- 「♻️ 清空回收站」：确认后清空全部（「确定永久清空回收站所有文件？此操作不可恢复！」），提示「♻️ 已清空 N 个文件」

### 3. 链接文件的安全策略

删除时按文件类型选择策略，避免破坏「整合包 ↔ 仓库」共享的数据：

| 文件类型 | 策略 |
|---------|------|
| 普通文件 | 移入 `.recycle`（保留相对目录结构），可恢复 |
| 硬链接（链接数 > 1） | 直接删除链接本身，其它引用不受影响 |
| 符号链接 | 直接删除链接，目标文件不受影响 |
| 跨分区移动失败 | 自动改为复制后删除 |

> 这意味着：删掉仓库侧的硬链接引用，不会误伤整合包里的同一份数据；重名回收自动加 `(1)/(2)` 后缀。

### 4. 哪些删除会进回收站

| 入口 | 是否进回收站 |
|------|-------------|
| 右键「♻️ 移入回收站」（单文件/多选/文件夹） | ✅ |
| 去重删除的副本 | ✅ |
| 「清空此整合包的模型」（仓库已有同名的部分） | ✅ |
| `Delete` 键删除 | ❌ 硬删除，谨慎使用 |

## 常见问题

**Q：回收站里的文件占空间吗？**
A：普通文件移入 `.recycle` 仍占磁盘空间，确认无用后永久删除或清空回收站。

**Q：恢复的文件回到哪里？**
A：按回收站内保留的相对路径还原到原位置（哪个资源根目录下的 `.recycle`，就还原到哪个根目录）。

**Q：回收站在磁盘哪里？**
A：每个资源根目录下各有一个 `.recycle` 子目录（如 `<存储路径>/ysm/.recycle`），备份仓库时会一并备份。
