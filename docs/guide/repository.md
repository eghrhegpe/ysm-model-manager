# 模型仓库

## 它能做什么

浏览和管理你的全部资源文件：树形目录、搜索、启用/禁用、批量操作、右键菜单整理，以及右侧预览面板（2D 骨骼图 / 3D 预览 / 详情）。仓库按资源类型分区管理，YSM 模型之外还支持 MMD、VRC、资源包、光影包、蓝图与投影文件。

## 打开方式

主界面左侧导航栏 →「📚 模型仓库」。页面顶部有五个 tab：

| tab | 内容 |
|-----|------|
| 📁 文件树 | 默认视图，树形浏览与管理（本篇） |
| 📥 导入 | 导入队列与命名表单，见 [导入队列与命名表单](./import-queue.md) |
| ♻️ 回收站 | 见 [回收站](./recycle-bin.md) |
| 🔗 去重 | 见 [模型去重](./model-dedup.md) |
| 👴 资历最深 | 见 [仓库元老](./oldest-models.md) |

文件树 tab 下还有第二行资源类型子标签：`💎 YSM` / `🎭 MMD` / `🥽 VRC` │ `🎨 资源包` / `☀️ 光影包` / `⚙️ 蓝图` / `📐 投影`，点击切换不同类型的仓库目录（选择会被记住）。

## 操作步骤

### 1. 树形浏览

- 文件树按文件夹结构展示当前类型仓库的所有文件，默认按名称排序
- 顶部排序下拉可切换 名称 / 大小 / 日期 三种排序
- 单击文件 → 右侧预览面板加载详情/预览；`Ctrl`/`⌘` 点击加选、`Shift` 点击区间选
- 点击文件夹箭头展开/收起（展开状态会自动保存）
- 以 `_` 开头的文件夹带 🔒 标记，为系统锁定目录
- 右上角 `☰`/`▦` 按钮可切换树形/列表两种视图
- 底部状态栏显示「共 N 项 (已启用 X) · 总大小」；未配置仓库时显示「📁 未设置」，点击可跳转设置页

### 2. 搜索

- 顶部搜索框（占位「🔍 搜索模型名称...」）按文件名/路径搜索，匹配字符高亮
- 搜索时匹配的文件夹自动展开；无结果时显示「🔍 未找到匹配的文件」
- `Ctrl+F` 快速聚焦搜索框

### 3. 启用 / 禁用

- 点击文件行前的开关切换启用/禁用：**禁用 = 文件重命名加 `.ban` 后缀**，游戏不会加载；启用则去掉后缀
- 文件夹旁的开关可批量切换该文件夹下所有模型：绿色 = 全启用，黄色 = 部分启用，灰色 = 全禁用
- 工具栏「⚡ 批量 ▾」→「✅ 全部启用」/「全部禁用」一键切换当前列表
- 硬链接模式下启用/禁用会即时同步到所有整合包（文件监听自动联动）

### 4. 右键菜单

| 对象 | 菜单项 |
|------|--------|
| 单文件 | ✂️ 重命名 / 📂 移动到… / 📋 复制到… / 📦 推送到整合包… / 🏷️ 编辑标签 / ♻️ 移入回收站 / 📂 打开文件位置 / 📋 复制文件路径 |
| 多选文件 | ✂️ 批量重命名... / 📂 移动到… / 📋 复制到… / ♻️ 移入回收站 / 📋 复制文件路径列表 / 📄 导出文件名清单 (.txt) |
| 文件夹 | ✂️ 重命名… / 📝 批量重命名… / 🗂 新建子文件夹… / ♻️ 移入回收站 |

- 「移动到…」「复制到…」弹窗输入目标文件夹名（如 `[作者名]`），禁止 `..` 与绝对路径
- 「移入回收站」有二次确认，删除后随时可恢复；**注意 Delete 键是硬删除，不进回收站**（见 [键盘快捷键](./keyboard-shortcuts.md)）

### 5. 文件行快捷操作

- 悬停文件行出现两个按钮：🔍 用作者名打开 B 站搜索、📋 复制文件名
- 有标签的文件显示 🏷️ 角标
- 大小列带颜色提示：<1MB 绿色、1–3MB 默认、≥3MB 红色

### 6. 工具栏「⋮ 更多 ▾」

- 导入文件 / 📁 导入文件夹（资源包、光影包、蓝图等类型可用）
- ☑️ 全选
- 骨骼结构：批量导出整个仓库的骨骼结构报告（`bone-structures-日期.txt`）
- 📂 打开文件夹 / 🔄 刷新
- 📇 生成索引：扫描仓库生成 `index.json`（供创意工坊在线浏览），同时自动生成 GitHub Actions 工作流

## 常见问题

**Q：模型列表为空？**
A：确认文件存储路径配置正确（[首次配置](./first-setup.md)），且当前类型子目录（如 `ysm/`）下存在对应扩展名的文件。

**Q：启用了模型但游戏中没变化？**
A：① 确保整合包已安装 YSM 模组；② 游戏中按 F3+T 重载资源包；③ 硬链接模式即时同步，复制模式的旧文件需要重新推送（见 [整合包同步](./pack-sync.md)）。

**Q：如何把文件整理到作者文件夹？**
A：右键「📂 移动到…」或「📋 复制到…」，输入目标文件夹名即可（不存在会自动创建）。树节点不支持拖拽移动。

**Q：如何给仓库生成在线索引？**
A：工具栏「⋮ 更多 ▾」→「📇 生成索引」，程序扫描仓库在仓库根生成 `index.json`，提交到 GitHub 后即可在创意工坊在线浏览。
