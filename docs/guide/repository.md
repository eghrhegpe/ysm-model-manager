# 模型仓库

## 它能做什么

浏览和管理你的模型文件集合：树形目录、搜索、排序、启用/禁用、批量操作、拖拽移动与 3D 预览。

## 打开方式

主界面左侧导航栏 →「📦 模型仓库」。

## 操作步骤

### 1. 树形浏览

- 左侧文件树按文件夹结构展示所有模型
- 点击模型文件 → 右侧面板显示 2D 骨骼图与 3D 预览

### 2. 搜索与排序

- 顶部搜索框按文件名搜索，匹配字符高亮
- 可按名称、大小、修改日期排序

### 3. 启用 / 禁用

- 点击文件前面的开关切换（禁用后文件加 `.ban` 后缀，游戏中不显示）
- 点击文件夹旁的按钮可批量开关该文件夹下所有模型（绿色=全启用，灰色=全禁用，黄色=混合）
- 勾选多个文件后可批量启用/禁用

### 4. 右键菜单

- 禁用/启用
- 查看模型详情
- 打开所在文件夹

### 5. 拖拽移动

在文件树中拖拽文件到不同文件夹，即可移动整理。

### 6. 3D 预览

点击模型文件后，右侧面板显示 3D 骨骼模型，支持旋转、缩放查看。部分高面数模型（>2000 cubes）可能卡顿，稍等片刻即可。

## 常见问题

**Q：模型列表为空？**
A：确认仓库路径配置正确（[首次配置](./first-setup.md)），目录下存在 `.ysm` / `.zip` / `.7z` 文件。

**Q：启用了模型但游戏中没变化？**
A：① 确保整合包已安装 YSM 模组（1.0.0+）；② 尝试按 F3+T 重载资源包；③ 硬链接模式即时同步，复制模式需重新安装（见 [整合包同步](./pack-sync.md)）。

**Q：如何给仓库生成在线索引？**
A：在仓库页点击「📇 生成索引」，程序扫描整个仓库生成 `docs/index.json`，提交到 GitHub 后即可在创意工坊在线浏览。
