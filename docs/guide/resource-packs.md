# 资源包管理

## 它能做什么

在仓库中管理**资源包类**资源——「🎨 资源包」（resourcepack）与「☀️ 光影包」（shaderpack）：与模型同一套文件树操作（启用/禁用、重命名、回收站、预览），并通过整合包同步推送进游戏。

## 打开方式

「📚 模型仓库」→「📁 文件树」tab → 第二行资源类型子标签选择「🎨 资源包」或「☀️ 光影包」。

## 操作步骤

### 1. 浏览与管理

- 文件树列出对应仓库目录（`resourcepacks/` 或 `shaderpacks/`）下的 `.zip` 文件
- 支持与模型一致的操作：开关启用/禁用（禁用 = 加 `.ban` 后缀，游戏不会读取）、右键重命名/移动/回收站、搜索、批量开关

### 2. 预览

点击资源包文件，右侧预览面板显示：

- `pack.png` 缩略图（像素化渲染；缺失时显示「❌ 无pack.png」）
- 包描述（来自 `pack.mcmeta`，支持 § 格式码）
- `pack_format` 与适配的 Minecraft 版本范围

### 3. 导入

- 拖入含 `pack.mcmeta` 的 `.zip` 会自动识别为资源包；含 `shaders/` 目录的识别为光影包（见 [模型导入](./import-model.md)）
- 资源包子标签下也可用文件树「⋮ 更多 ▾」→「导入文件 / 📁 导入文件夹」直接选择导入

### 4. 推送进游戏

- 在「🎮 整合包管理」中，资源包与光影包作为独立类型参与推送/拉取（「推送所选」菜单可选 🎨 资源包 / ☀️ 光影包）
- 推送目标：整合包的 `resourcepacks/` 或 `shaderpacks/` 目录；链接模式规则与模型一致（见 [整合包同步](./pack-sync.md)）

## 常见问题

**Q：资源包和模型能放在同一个仓库吗？**
A：可以。统一存储路径下按类型分子目录（`ysm/`、`resourcepacks/`、`shaderpacks/` 等），文件树通过子标签切换，互不干扰。

**Q：光影包不生效？**
A：① 确认推送到了目标整合包（状态为 ✅ 已同步）；② 确认游戏内已启用该光影（光影加载器设置）；③ 确认 zip 内有 `shaders/` 目录，否则可能被误判类型。

**Q：如何快速区分资源包 zip 和模型 zip？**
A：预览面板会给出答案——能读取出 `pack.mcmeta` 信息的是资源包；模型 zip 显示的是 YSM 模型详情。
