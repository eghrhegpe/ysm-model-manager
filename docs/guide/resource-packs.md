# 资源包管理

## 它能做什么

在仓库中管理**资源包类**资源（`resourcepack` / `shaderpack`）：浏览、启用、切换，与模型文件分开管理。

## 打开方式

在「模型仓库」页面的资源类型切换中选择「资源包」/「光影包」标签，进入资源包管理面板。

## 操作步骤

### 1. 资源类型入口

- **资源包（resourcepack）**：纹理、材质等资源
- **光影包（shaderpack）**：着色器资源

两类资源由同一管理组件驱动（`app-resource-manager`），交互一致。

### 2. 浏览与启用

- 面板列出仓库中的资源包文件
- 操作与模型仓库一致：启用/禁用、查看详情

### 3. 与游戏整合包的关系

资源包启用后同样通过链接模式同步到整合包，规则见 [整合包同步](./pack-sync.md)。

## 常见问题

**Q：资源包和模型能放在同一个仓库吗？**
A：可以。仓库按资源类型分类管理，资源包/光影包与模型分属不同标签页。

**Q：光影包不生效？**
A：确认资源类型正确选择为 shaderpack，且已启用并同步到目标整合包。
