# 设置

## 它能做什么

集中配置程序运行所需的一切：路径、链接模式、下载镜像源、主题外观、字体布局、动画与默认页面。设置页分四个 tab：「⚙️ 常规」「🎨 外观」「🕹️ 3D 预览」「ℹ️ 关于」。
## 打开方式

主界面左侧导航栏 →「⚙️ 设置」。

## 操作步骤

### 1. 常规

- **🎮 游戏根目录**：显示当前 `.minecraft` 路径，「🔍 自动搜索」扫描常见启动器位置；悬停按钮可查看扫描范围。详见 [首次配置](./first-setup.md)
- **链接模式**：📋 复制 / 🔗 硬链接 ✅ / 🔗 符号链接，切换即保存并自动重新链接；「🔄 重新应用」手动重链
- **下载镜像源**：🌍 直连（raw.githubusercontent.com）/ ⚡ jsDelivr CDN（国内加速，缓存约 12 小时）/ 🐙 GitHub API（未认证 60 次/小时）。三个源实际是「优先顺序 + 全部回退」，某个源失败会自动尝试下一个
- **文件存储路径**：点击路径文字更换目录；「📂 展开 ▸」可为各资源类型单独设路径或「↩️ 默认」恢复
- **🏠 启动默认页面**：选择启动时打开的页面（🎮 整合包管理 / 🎨 创作者频道 / 📦 模型仓库），并可选择记住上次访问的页面
- **🌐 语言**：切换界面语言，需重新加载页面生效

### 2. 外观

- **🌙 主题与外观**：6 张主题卡片直接点选（详见 [主题外观](./themes.md)）；「🕐 自动切换」可选关闭 / 跟随系统亮暗 / 按时间段（白天暖色、夜晚冷色）
- **📐 字体与布局**：基准字号（🔹 极小 −2px / 🔹 小 −1px / 🔸 标准 / 🔺 大 +1px / 🔺 很大 +2px，实时预览）、创作者字体（🖌️ 楷体 / 📝 系统字体）、卡片密度（📦 紧凑 / 📦 标准）
- **⚡ 行为与动画**：「✨ 启用过渡动画」勾选框（关闭后移除 hover 与淡入淡出，适合低配设备）

### 3. 3D 预览

- **🕹️ 3D 预览设置**：相机移动速度滑块、默认旋转模式（环绕模型 / 自由相机）、6 个操作键位（点击按钮后按任意键重绑，方向键始终兜底；支持「恢复默认键位」）。键位以物理键 `KeyboardEvent.code` 存储，跨键盘布局（如 AZERTY）一致。
- **🔧 解析 worker**：FBX 与 MMD 默认在主线程解析；开启 worker 后移入 Web Worker，异常时自动回退主线程，也可在此手动关闭。

### 4. 关于

- **📦 当前版本**：显示版本号（如 `v1.9.3`）
- **🔄 检查更新**：手动检查 GitHub Releases，并可设置检查更新间隔（详见 [版本更新](./update.md)）
- **📋 发布页**：用系统浏览器打开 GitHub Releases
- 功能介绍、技术栈、资源链接与快速上手引导
- **🙏 鸣谢**：灵感来源（下载队列、3D 渲染、YSM 解析、硬链接/回收站理念的参考项目）与特别鸣谢名单

## 自动保存的状态

设置项分布在**两个存储层**，耐久性不同——备份时请注意覆盖面差异。

| 内容 | 保存位置 | 备份 |
|------|---------|------|
| 路径 / 链接模式 / 主题与自动模式 / 镜像源 / 更新检查间隔 / 日志上限 / 各资源类型自定义根 | `%APPDATA%\YSM-Model-Manager\ysm_config.json` | ✅ 复制文件即可 |
| 窗口位置与大小 | 同上（退出时保存，启动恢复，双屏按相对位置） | ✅ |
| 界面偏好：字号 / 创作者字体 / 卡片密度 / 动画开关 | 浏览器本地存储（localStorage） | ❌ |
| 3D 偏好：相机速度 / 旋转模式 / 键位映射 | 浏览器本地存储（localStorage） | ❌ |
| 解析开关：FBX / MMD worker | 浏览器本地存储（localStorage） | ❌ |
| 启动默认页与「记住上次访问」 | 浏览器本地存储（localStorage） | ❌ |
| 导航页 / 预览面板宽度 / 资源类型 tab / 目录展开状态等 | 浏览器本地存储（localStorage） | ❌ |

> ⚠️ **localStorage 里的设置不在 `ysm_config.json` 内**：清理浏览器数据、WebView2 用户配置被重置或换设备时，这些设置会回到默认值，需要重新配置一次。主题是唯一的例外——它在 localStorage 与 `ysm_config.json` 中各存一份（后者供备份兜底）。

## 常见问题

**Q：配置存在哪里？**
A：路径 / 链接模式 / 主题 / 镜像源等在 `%APPDATA%\YSM-Model-Manager\ysm_config.json`（不是 exe 同目录）；界面与 3D 偏好（字号、字体、密度、动画、键位、相机速度、旋转模式、解析开关、启动默认页）在浏览器的 localStorage 中，**不包含在该文件里**。旧版放在 exe 旁的配置文件会在启动时自动迁移过来。

**Q：备份 `ysm_config.json` 就能保留所有设置吗？**
A：不能——它只覆盖上表第一行的配置类设置。字号、键位、启动页等 localStorage 类设置需要另行记录（见上表）。

**Q：改了文件存储路径后模型列表没变？**
A：路径保存后仓库会重新扫描；若仍为空，确认新目录下对应类型子目录中存在资源文件（如 `ysm/` 下的 `.ysm` / `.zip` / `.7z`）。

**Q：回收站、去重在哪设置？**
A：它们不是设置项——回收站与去重是「📦 模型仓库」页面的独立 tab，见 [回收站](./recycle-bin.md) 与 [模型去重](./model-dedup.md)。

**Q：高级面板里的资源类型路径怎么恢复默认？**
A：设过自定义根的卡片标题旁会出现「已自定义」标记与「↩️ 默认」按钮，点它即可清空该类型的自定义路径，回到 `文件存储根目录/{子目录}`。该按钮只在**确实有自定义根**时出现。
