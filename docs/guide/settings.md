# 设置

## 它能做什么

集中配置程序运行所需的一切：路径、链接模式、主题外观、回收站与界面状态自动保存。

## 打开方式

主界面右上角 →「⚙️ 设置」。

## 操作步骤

### 1. 路径

- **游戏根目录**：配置/自动搜索 `.minecraft` 路径
- **模型仓库路径**：配置模型文件存放目录
- 详见 [首次配置](./first-setup.md)

### 2. 链接模式

切换安装方式：硬链接（推荐）/ 复制 / 符号链接。详见 [首次配置](./first-setup.md) 链接模式章节。

### 3. 主题模式

4 套主题可选：

- 💻 跟随系统
- 🌙 赛博霓虹（深色）
- ☀️ 温暖木纹（浅色）
- ⚪ 极简深邃

### 4. 回收站

查看、恢复或永久删除已回收文件。详见 [回收站](./recycle-bin.md)。

### 5. 自动保存

导航状态和窗口位置在关闭时自动保存，下次启动恢复。

## 常见问题

**Q：配置存在哪里？**
A：`ysm_config.json`（与 exe 同目录）。备份此文件即可保留所有设置；模型仓库本身是文件集合，建议另外备份。

**Q：改了路径后模型列表没变？**
A：路径保存后仓库会重新扫描；若仍为空，确认新目录下存在 `.ysm` / `.zip` / `.7z` 文件。
