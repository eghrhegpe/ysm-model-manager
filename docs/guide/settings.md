# 设置

## 它能做什么

集中配置程序运行所需的一切：路径、链接模式、下载镜像源、主题外观、字体布局、动画与默认页面。设置页分四个 tab：「⚙️ 基础设置」「⚙️ 界面与体验」「ℹ️ 关于」「🙏 鸣谢」。

## 打开方式

主界面左侧导航栏 →「⚙️ 设置」。

## 操作步骤

### 1. 基础设置

- **🎮 游戏根目录**：显示当前 `.minecraft` 路径，「🔍 自动搜索」扫描常见启动器位置；悬停按钮可查看扫描范围。详见 [首次配置](./first-setup.md)
- **链接模式**：📋 复制 / 🔗 硬链接 ✅ / 🔗 符号链接，切换即保存并自动重新链接；「🔄 重新应用」手动重链
- **下载镜像源**：🌍 直连（raw.githubusercontent.com）/ ⚡ jsDelivr CDN（国内加速，缓存约 12 小时）/ 🐙 GitHub API（未认证 60 次/小时）。三个源实际是「优先顺序 + 全部回退」，某个源失败会自动尝试下一个
- **文件存储路径**：点击路径文字更换目录；「📂 展开 ▸」可为各资源类型单独设路径或「↩️ 默认」恢复

### 2. 界面与体验

- **🌙 主题与外观**：6 张主题卡片直接点选（详见 [主题外观](./themes.md)）；「🕐 自动切换」可选关闭 / 跟随系统亮暗 / 按时间段（白天暖色、夜晚冷色）
- **📐 字体与布局**：基准字号（🔹 小 / 🔸 标准 / 🔺 大，实时预览）、创作者字体（🖌️ 楷体 / 📝 系统字体）、卡片密度（📦 紧凑 / 📦 标准）
- **⚡ 行为与动画**：「✨ 启用过渡动画」勾选框（关闭后移除 hover 与淡入淡出，适合低配设备）；「🏠 启动默认页面」（🎮 整合包管理 / 🎨 创作者频道 / 📦 模型仓库）

### 3. 关于

- **📦 当前版本**：显示版本号（如 `v1.9.3`）
- **🔄 检查更新**：手动检查 GitHub Releases（详见 [版本更新](./update.md)）
- **📋 发布页**：用系统浏览器打开 GitHub Releases
- 功能介绍、技术栈、资源链接与快速上手引导

### 4. 鸣谢

灵感来源（下载队列、3D 渲染、YSM 解析、硬链接/回收站理念的参考项目）与特别鸣谢名单。

### 5. 自动保存的状态

| 内容 | 保存位置 |
|------|---------|
| 路径 / 链接模式 / 主题 / 镜像源 | `%APPDATA%\YSM-Model-Manager\ysm_config.json` |
| 窗口位置与大小 | 同上（退出时保存，启动恢复，双屏按相对位置） |
| 导航页 / 预览面板宽度 / 资源类型 tab / 目录展开状态等 | 浏览器本地存储（localStorage） |

## 常见问题

**Q：配置存在哪里？**
A：`%APPDATA%\YSM-Model-Manager\ysm_config.json`（不是 exe 同目录）。备份此文件即可保留所有设置；旧版放在 exe 旁的配置会在启动时自动迁移过来。

**Q：改了文件存储路径后模型列表没变？**
A：路径保存后仓库会重新扫描；若仍为空，确认新目录下对应类型子目录中存在资源文件（如 `ysm/` 下的 `.ysm` / `.zip` / `.7z`）。

**Q：回收站、去重在哪设置？**
A：它们不是设置项——回收站与去重是「📦 模型仓库」页面的独立 tab，见 [回收站](./recycle-bin.md) 与 [模型去重](./model-dedup.md)。
