# 标签管理

## 它能做什么

给模型打上自定义标签（如「机甲」「古风」），随模型元数据保存；后续可在高级筛选中按标签快速过滤。有标签的文件在文件树中显示 🏷️ 角标。

## 打开方式

- **编辑标签**：文件树中右键模型文件 →「🏷️ 编辑标签」
- **按标签筛选**：工具栏「⚙️ 筛选」打开高级筛选，使用其中的标签条件

## 操作步骤

### 1. 添加标签

1. 打开「🏷️ 编辑标签」弹窗（标题下方显示模型路径）
2. 在输入框（占位「输入标签后按 Enter」）输入标签后按 `Enter`，或点「+ 添加」
3. 也可展开「📋 已有标签（点击添加）」，点击 `+标签` 按钮直接添加仓库中出现过的其它标签（没有时显示「暂无其他标签」）

### 2. 删除与保存

- 在已添加列表中移除不需要的标签
- 点「💾 保存」写入模型元数据，成功 toast「🏷️ 已保存 N 个标签」；「取消」或按 Esc 放弃修改

### 3. 按标签筛选

- 打开「⚙️ 高级筛选」，在「🏷️ 标签（留空不限）」输入标签名
- 弹窗会异步加载已有标签提示（「已有标签: xxx, yyy」），方便补全
- 可与其他筛选条件（关键词/骨骼数/立方体/纹理尺寸）组合，详见 [高级筛选](./advanced-filter.md)

## 常见问题

**Q：标签长度限制？**
A：单个标签最多 **20** 个字符（保存时校验，超出提示「⚠️ 标签最多 20 个字符」；输入框本身的硬上限是 30 字符）。

**Q：添加了重复标签？**
A：会提示「⚠️ 标签已存在」，不会重复加入。

**Q：标签存在哪里？**
A：随模型元数据保存在模型文件内；读取失败会提示「⚠️ 加载标签失败」。
