# 主题外观

## 它能做什么

切换界面主题外观：6 套内置主题一键切换，支持跟随系统亮暗或按时间段自动切换；全部样式走 CSS 变量，切换即时生效并持久保存。

## 打开方式

「⚙️ 设置」→「⚙️ 界面与体验」→「🌙 主题与外观」。

## 操作步骤

### 1. 主题列表

点击主题卡片立即切换：

| 主题 | 风格 |
|------|------|
| ☀️ 温暖木纹（warm） | 浅色木纹风 |
| 🌸 樱花物语（sakura） | 浅色樱花粉 |
| 🍃 薄荷物语（mint） | 薄荷浅色 |
| ⚪ 极简深邃（pro） | 极简深色 |
| 🌙 赛博霓虹（cyber） | 深色霓虹风（默认主题） |
| 🌊 深海探秘（ocean） | 深海蓝调 |

> 手动点选主题卡片会自动关闭「自动切换」。

### 2. 自动切换

「🕐 自动切换」下拉三种模式：

| 模式 | 行为 |
|------|------|
| 关闭 | 固定使用当前主题 |
| 跟随系统亮暗 | 跟随 Windows 深浅色：深色 → 赛博霓虹，浅色 → 温暖木纹；系统切换时实时跟随 |
| 按时间段 | 6:00–18:00 用温暖木纹，其余时间用赛博霓虹 |

### 3. 字体与密度（同页配置）

- **📏 基准字号**：🔹 小（−1px）/ 🔸 标准 / 🔺 大（+2px），下方实时预览正文与按钮效果
- **🃏 创作者字体**：创作者卡片名字用 🖌️ 楷体（更文艺）或 📝 系统字体（更简洁）
- **💳 卡片密度**：📦 紧凑（信息密集）/ 📦 标准（间距舒适）

### 4. 状态保存

主题选择同时保存在本地存储与配置文件（`theme` 字段），重启程序后保持；跟随系统/按时间段的模式设置同样持久化。

## 常见问题

**Q：跟随系统没生效？**
A：确认 Windows 已开启深色/浅色模式；程序监听系统主题变化实时切换，并会 toast 提示「已跟随系统切换至深色/浅色主题」。

**Q：有没有快速切换按钮？**
A：当前版本主题入口集中在设置页；主界面没有独立的快速切换按钮。
