# 主题外观

## 它能做什么

切换界面主题外观，支持跟随系统与多套内置主题，切换时带扩散动效。

## 打开方式

「⚙️ 设置」页面 → 主题模式，或点击主界面右上角主题按钮快速切换。

## 操作步骤

### 1. 主题列表

| 主题 | 风格 |
|------|------|
| 💻 跟随系统 | 自动跟随 Windows 深浅色 |
| 🌙 赛博霓虹（cyber） | 深色霓虹风 |
| ☀️ 温暖木纹（warm） | 浅色木纹风 |
| ⚪ 极简深邃（pro） | 极简深色 |
| 🍃 薄荷物语（mint） | 薄荷浅色 |

### 2. 切换动效

切换主题时界面带圆形扩散（ripple）动画，从点击位置展开。

### 3. 状态保存

主题选择保存在本地（localStorage），重启程序后保持。

## 常见问题

**Q：跟随系统没生效？**
A：确认 Windows 深浅色模式已开启；程序启动时读取一次，切换系统主题后可在设置页重新选择。
