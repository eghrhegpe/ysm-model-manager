# 创意工坊

## 它能做什么

在线浏览和下载 GitHub 上的 YSM 模型仓库：读取远程 `index.json` 浏览模型列表，一键下载到本地仓库。

## 打开方式

主界面左侧导航栏 →「🧩 创意工坊」。

## 操作步骤

### 1. 仓库列表

查看已配置的 GitHub 仓库源。

### 2. 模型浏览

读取远程 `index.json`，在线浏览模型列表（文件名、大小等）。

### 3. 一键下载

点击 ⬇️ 直接下载到本地仓库，随后可在 [模型仓库](./repository.md) 中查看。

## 常见问题

**Q：自己的仓库怎么让别人在线浏览？**
A：在「模型仓库」页面点击「📇 生成索引」，程序扫描整个仓库生成 `docs/index.json`，将此文件提交到 GitHub 仓库即可。

**Q：下载失败 / 卡在进度条？**
A：检查网络连接与代理设置；下载进度异常时可重启程序重试。
