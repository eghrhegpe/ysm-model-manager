# 创意工坊

创意工坊汇集社区维护的 GitHub 模型仓库，可以直接把模型下载到本地仓库，不用手动找网盘、解压、安装。

## 打开方式

导航栏点击「🧩 创意工坊」。左侧选择仓库源（目前收录 5 个社区仓库），右侧显示该仓库的文件列表。

## 浏览与搜索

列表顶部提供：

- **搜索框**：按文件名/路径过滤；
- **☐ 全选**：勾选当前列表全部文件；
- **📁 仅显示缺失**：隐藏本地已有的文件，只看还没下载的；
- 每个文件显示大小；本地已有的文件行显示「✓ 已有」徽标。

## 下载

- **单个下载**：点击文件行的下载按钮；
- **批量下载**：勾选多个文件后点击「⬇️ 下载选中 (N)」。

下载规则：

- 下载采用**三镜像源竞速**（GitHub raw / jsDelivr / GitHub API），谁先响应用谁，单个源 8 秒超时自动切换，提高国内网络成功率；
- 文件按仓库中的相对路径下载到本地仓库的 `ysm/` 目录；
- 大文件保护：超过 10MB 的文件拒绝下载；超过 4MB 会先弹出确认；
- 下载进度见《下载队列》，完成后文件树自动刷新，新模型直接可用。

## 常见问题

- **列表加载不出来**：网络无法访问三个镜像源（需要科学上网或稍后重试）；
- **显示「该仓库未收录索引」**：该仓库没有索引文件（404），无法列出内容；
- **下载失败**：查看底部错误提示；队列支持失败后重试（重新触发下载即可，会再次三源竞速）；
- **下载后找不到文件**：文件在 `ysm/` 子目录下，按文件树的 ysm 子标签查找。

## 相关功能

- 《下载队列》——下载进度、失败与保护机制
- 《导入模型》——把外部文件导入仓库的另一种方式
