# 国际化 i18n 模块

## 概览

`i18n` 模块是 YSM 前端的唯一翻译层，基于 ADR-045 设计。`t.ts` 提供纯函数式翻译（按 key 查表），`locale.ts` 管理语言状态、持久化与异步加载。支持简体中文（基准）、英语、日语三种语言，语言偏好持久化到 `localStorage`，切换时通过 `bus` 广播 `lang:changed` 事件驱动全量重渲染。

## 核心职责

- **翻译查表**: `t(key, params?)`（严格 LocaleKey 入口）/ `tOf(key, params?)`（string 入口，动态 key）— 从当前语言包取字符串，支持 `{key}` 插值；缺失时返回 key 本身（经 `warnMissingKey` 单次 `console.warn`）；插值走 split/join 字面量替换（对 `$&`/`$1` 特殊序列免疫）+ **残留占位符守卫**：替换后文本仍含 `{ident}` → 按残留签名告警一次（堵「模板有 `{n}` 漏传参」裸占位符上屏，ADR-207 D3）
- **缺失键兜底双入口**: `tr(key: LocaleKey, fallback, params?)` 严格字面量入口（拼错编译期报红）/ `trDynamic(key: string, fallback, params?)` 数据驱动入口（`labelKey` 数据字段 + 原文兜底，如 3D 菜单 cap-controls、右键菜单 BATCH_TPL 模板表）— 二者共享 `tOf`（缺失键返回 key 本身 → 走 fallback 插值）；`LocaleKey | (string & {})` 洗白 union + `as` cast 已退役（ADR-207 D3）。菜单声明表（`menu-defs.ts`）、3D 预览菜单、右键菜单 handler 统一经此防裸 key 字面量（`runBatchFileOp` 用 `BATCH_TPL` mode 模板表集中定义 move/copy 文案）
- **语言状态管理**: `_currentLang` 持久化到 `localStorage.uiLang`，启动时优先读持久值，其次检测 `navigator.languages`，兜底 `zh-CN`
- **语言包异步加载**: `loadLocale(lang)` — 从 `public/locales/{lang}.json` fetch；幂等缓存 + 在途 Promise 去重（`pendingLoads`，并发同语言只发一次 fetch，失败后在途表清空可重试）；失败不缓存空对象（删除键允许重试）
- **初始化**: `initI18n()` — 读取持久化/系统语言 → 预加载 → 同步 `document.documentElement.lang` → 成功后 emit `lang:changed`（补发一次让首帧渲染的空 bundle 组件重渲染）
- **并发安全**: `setLang()` 用 `_langReqGen` 代际计数，快请求后到可覆盖旧写入，防竞态
- **缺失 key 告警节流**: `warnMissingKey(key)`（每 key 一次；可变 Set 保持模块内私有，ADR-207 D3 收编），切语言时清空节流表

## 对外 API / 入口

- `t(key: LocaleKey, params?)` — 严格字面量 key 翻译（拼错编译期报错；动态 string key 用 `tOf`/`trDynamic`）
- `tOf(key: string, params?)` — string 版 t（动态 key；缺失语义与 t 同构）
- `tr(key: LocaleKey, fallback, params?)` / `trDynamic(key: string, fallback, params?)` — 缺失键兜底双入口
- `getLang()` — 读取当前语言代码（`LangCode`）
- `setLang(code)` — 切换语言（异步，加载语言包后触发 `lang:changed`）
- `initI18n()` — 启动时调用，读取持久化/系统语言并预加载
- `getBundle(lang?)` — 获取翻译包（已加载时直接读缓存，空包回落 zh-CN）
- `SUPPORTED_LANGS` — 支持的语言常量列表（含 code / label / key）
- `warnMissingKey(key)` — 缺失 key 单次告警（locale 模块内节流）

## 与其他子系统关系

- `bus`: `setLang` / `initI18n` 完成后 emit `lang:changed`，订阅者（app-nav / app-content / 各组件）据此重渲染
- `storage.ts` (`safeGet`/`safeSet`): 用于 `localStorage.uiLang` 读写，避免隐私模式裸调抛错中断启动链
- `scripts/generate-locale-json.ts`: 从 TS 源文件生成运行时 JSON，放在 `public/locales/`
- `zh-CN.ts` 是基准语言包，`en.ts` / `ja.ts` 须与之一一对应（脚本可校验完整性）
- **新增翻译 key 同步规则**：新增 key 须三语言同时添加，由 `i18n-check` 脚本校验完整性

## 不变量

- 基准语言为 `zh-CN`，未知语言回落 `zh-CN`，再 fallback 到空对象
- 语言切换须走 `setLang`（不可直接修改 `_currentLang`）
- 语言包加载失败时删除缓存键（非缓存空对象），允许后续重试
- 隐私模式下 `localStorage` 读写经 `safeGet`/`safeSet` 包装，静默降级不中断流程
- **键名迁移 = 同步改调用点 + 删旧键**（ADR-124 §2.3 实施调整）：改名键时同步改全部调用点 + 测试断言 + 三语言包，旧键从语言包直接删除；**无 `legacy-key-map.ts` 兼容表**。禁止「保留旧键等兼容回退」——旧键残留是 i18n_accuracy.md 记录的「改旧键以为生效实则无效」陷阱根源
- 模板含 `{ident}` 占位符的调用必须传 params（残留守卫按签名告警一次，裸占位符不上屏）
