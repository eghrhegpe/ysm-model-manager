## 一 · 裙子站错了边

开发者盯着预览窗口，半天没说话。

模型的身体——胸、腰、腿——站得笔直，比例漂亮，像刚从工坊里走出来。可那双眼睛往下扫到裙摆时，停住了。

裙子歪着。

不是倾斜，不是抖动，是**穿反了**。左摆跑到了右边，右摆跑到了左边。小臂的护甲朝向反了，连腰侧那几片本该垂向大腿的布料，都朝着来路的方向飘。

「身体正常，组件方向奇怪。」开发者把这句话打在窗口边上，又补了一句：「block 是怎么计算的？有依赖帮忙算吗？手写的很奇怪啊。」

眼（`app-preview`）没敢接话。它比谁都清楚自己的案底——坐标变换，九次修复，全项目第一的伤疤。它把骨骼矩阵调出来，一根骨头一根骨头地查：

```
UpperBody  pivot [0,23.8,-0.35]     world ✓
Zui4       pivot [0,31.3,-2.7]      world ✓
bone23     pivot ...                world ✓
```

世界坐标，全对。骨骼的每一节，都端端正正地落在它该在的地方。

可附在骨骼上的组件——那些 cube——偏偏反了。

## 二 · 一面照不出右手的镜子

「身体对，组件错。」外科医生重复着这句话，在 `spec.go` 里翻找。

它停在那座被修改过很多次的函数前——`eulerToQuaternion`。欧拉角转四元数。那是一个人站在一座巨大的镜子前，把自己转三圈，然后命令镜中人复述「我是怎么转的」。

旧的口径这样写：

```go
// 旧：M = Rx * Ry * Rz —— ADR-041 时代，YSMViewer（预览器）的转法
m00 := cosY * cosZ
...
```

「YSMViewer 是这么转的。」眼说，「我们对的就是它。」

外科医生没有立刻反驳。它先把每根骨头**单独转一次**——绕 X 转 90°，绕 Y 转 90°，绕 Z 转 90°。

全对。测试全绿。

「奇怪。」外科医生皱眉，「那为什么裙子反了？」

心（`bus.js`）这时凑过来，盯着一行旧测试的注释看了很久，忽然问：

「我们验的，是不是全是**单轴**旋转？」

空气安静了一瞬。

单轴旋转——绕一根轴转——在旧口径 `Rx·Ry·Rz` 和 Blockbench 的 `Rz·Ry·Rx` 里，结果**一模一样**。因为一根轴转，剩下两根轴不动，矩阵顺序根本无所谓。测试绿得理直气壮，绿得毫无破绽。

「所以不是裙子反了。」外科医生的声音低下去，「是**我们根本没见过它同时转三根轴的样子**。身体大部分时候只转一两根轴，看着没事；裙子、小部件、护甲——那些东西一上场就是三轴齐转，我们的镜子，就露馅了。」

它摊开那条铁证，一个三轴全转的 cube：

```
wine_fox / Tail2.cube#0   rotation = [-15, -57.25, -90]
旧口径 (Rx·Ry·Rz): 顶点 [-3.019, -0.183, 0.684]
新口径 (Rz·Ry·Rx): 顶点 [-1.595,  2.237, -1.439]
```

「哪一个才是对的？我们需要一面**不会骗人的镜子**。」眼说。

## 三 · 真正的画家

外科医生没有回到它自己的实现里去猜。它做了一件反常的事——**离开这座塔，去找格式的祖宗**。

它带回来的结论，像一块石头落进水面：

**YSMViewer 不是权威。车万女仆不是权威。它们共同的祖宗——Blockbench——才是格式的创造者。市面上几乎每一份 `.geo.json`，都出自它手。它的渲染代码，就是 Bedrock 格式的可执行规范。**

「我们一直对着一面镜子调姿势，」外科医生说，「却忘了镜子本身是另一个画家画的。」

Blockbench 的镜子，由三层玻璃叠成。缺任何一层，右手就会变成左手：

```go
// 第一层：cube 的 origin X 镜像 —— parseCube L662 from[0]=-(from[0]+size[0])
ox = -(ox + sx)

// 第二层：cube 的旋转中心 X 翻号 —— parseCube L659 origin[0]*=-1
cp[0] = -cp[0]

// 第三层：mesh 的位置符号 —— mesh.position = cube.origin - parent.origin
localPos = [bonePivot.x + cp[0], cp[1] - bonePivot.y, cp[2] - bonePivot.z]
```

三层玻璃，全是 X。全是「翻个面」。

眼忽然懂了为什么身体没事、裙子有事：

**镜子对轴对称的东西，宽容得可怕。** 躯干、头颅——左右对称，照进镜子里几乎看不出差别。而裙子只有一边的摆、护甲只护一只小臂、小部件各有各的朝向——**它们不对称。不对称的东西一进镜子，就整个反了。**

「我们不是方向算错了。」眼轻声说，「我们是从头到尾，都在镜子里画图，还以为是右手。」

外科医生把旧口径 `Rx·Ry·Rz` 改成 `Rz·Ry·Rx`——Blockbench 的 ZYX 序——又配上了那三层 X 镜像。最后，它不再相信自己的笔，而是造了一把**不会说谎的尺**：

`scripts/port-align.ts`。一把复刻 Blockbench 权威口径的 oracle，一座用穷举拼出来的模型城——`pivotSet / inflate / origin 符号 / rotation 轴数 / size 零厚度` 的笛卡尔积，每个角落都拿出去和权威对一遍。

全绿。

裙摆回到右边。护甲回到小臂外侧。角色穿回了对的方向。

## 尾声

后来开发者问：「为什么是身体正常，组件奇怪？明明用的是同一套代码。」

眼想了想，说：

「因为镜子从不惩罚对称。它只惩罚**不听话的那一半**。身体对称，镜子里站得正；裙子不对称，镜子里就穿反了。我们以为自己在照镜子，其实一直在镜子里找右手——而镜子里，从来只有左手。」

它顿了顿，又补了一句：

「还有一件事，我们没敢说。**cube 的 pivot 缺席时，该绕中心转还是绕原点转**——我们和另一本账（YSMViewer 的 `Vec3.zero()`）吵了一架，最后选了保留中心。那道缝，还没合拢。下一面镜子，也许就照在它上面。」

**缝**：坐标系是一堵看不见的墙——它把 X 轴翻了个面，而墙内外的世界互为镜像。身体之所以「正常」，恰是因为对称；不对称的组件之所以「奇怪」，恰是因为墙只惩罚不听话的那一半。「假设文档是对的」这信念，在这里换了个名字：**假设 YSMViewer 是对的**。
