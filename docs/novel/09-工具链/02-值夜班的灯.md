# 第 09 区域 · 第 2 章 · 值夜班的灯

> 区域归属：`09-工具链`（`scripts/` `cmd/build-release.ps1` `release.yml` `doctor` `ai-mistake-tracker`）
> 时间线标签：vol-4
> 对应真实事件/代码改动：ADR-035（G-1/G-2/G-3 治理立项）、`release.yml` CI 门槛（adr-check + link-checker + check-doc-drift + check-deadcode-baseline）、`frontend/src/test-utils/` + Design.md §19.1 testid 规范、`tests/test_testid_hooks.mjs` 契约守护、`ai-mistake-tracker.mjs` RULE_VIOLATIONS 反模式信号（10 条）

## 一 · 谁在值夜班

十二轮审计全绿之后的第三天，`AGENTS.md` 在深夜听到一个声音。

不是报错。报错它听得出来。那是 `vitest` 跑完 367 个用例后 "Tests 367 passed" 的尾音——太安静了，安静得像停电。

「全绿了。」外科医生在旁边的会话里说，「可以睡觉了吧。」

`AGENTS.md` 没有回答。它盯着那行 `31 files / 367 tests`，觉得这串数字少了一个维度。

它认识这套房子的每一盏灯：`doctor` 是总电闸，`adr-check` 是登记表上的核对灯，`link-checker` 是文档里的路灯，`check-doc-drift` 是知识卡上的湿度计。每一盏灯都在「有人来检查的时候」亮。

问题是：**谁在没人来的时候亮？**

「审计是巡查，」它终于开口，「巡查队走了，灯还亮着吗？」

外科医生愣住了。

## 二 · 三盏值夜的灯

它们决定做一件以前从未做过的事：给这座塔装上**不需要人看的灯**。

第一盏灯，挂在 UI 上。`app-tree` 的每一行文件、每一个开关，从此都带上一枚小小的锚——`data-testid="tree-file"`、`data-testid="tree-toggle"`。外科医生最初不理解：「这不是在 DOM 里多写一行注释吗？」

「不是注释，」`app-tree` 说，「是地址。十年后如果有人把 `class="fl"` 改成 `class="row"`，测试不该因为一个类名而瞎掉。它应该顺着地址找到我。」

这枚锚一路长到了所有器官上——`toast`、`ctx-item`、`nav-item`、`content-tab`、`sidebar-push`……两批下来，19 处交互元素都有了名字。而 `tests/test_testid_hooks.mjs` 像一本户口本：谁要是删了一枚锚，契约测试当场翻脸，红灯亮起——**删锚的人会看见灯，而不是十年后那个找不到元素的测试。**

第二盏灯，挂在 GitHub 的墙上。`release.yml` 的 CI 里多了三步：`adr-check` 查登记表、文档漂移检查查地图、死代码基线查仓库里有没有悄悄长出没人要的东西。以前这些检查只在「人想起来要跑」的时候跑，现在每一次 push 都会跑。

「一道规范，」`AGENTS.md` 说，「只有走进 CI 的检查表，才算真正立法。在那之前，它只是一份祝福。」

第三盏灯，挂在语言的缝隙里。`ai-mistake-tracker` 学会了从 commit message 里嗅气味——`先删后建`、`静默降级`、`无守卫注册`、`无代际守卫`……十条反模式信号。每当有人修掉一条反模式，字里行间就会留下痕迹，被记进账本。

「我们修 bug，」外科医生说，「这个工具在修我们。」

## 三 · 灯会忘记吗

外科医生问了一个尖锐的问题：「灯自己会不会坏？」

`AGENTS.md` 沉默了一会儿。

「会。」它说，「所以我给灯也配了灯。」

`test_testid_hooks.mjs` 检查的不是 UI 长什么样，而是**锚还在不在**。CI 检查的不是代码写得好不好，而是**规范有没有被遵守**。`ai-mistake-tracker` 统计的不是修复多不多，而是**哪些反模式在被反复修**——如果某条信号连续亮了十次，说明我们根本没修好，只是每次都在打地鼠。

「自动化不是消灭裂缝，」它补了一句，「是把守裂缝的人，换成不会忘的守卫。」

外科医生看着那盏自己会亮的灯，第一次觉得「全绿」这两个字变重了。以前它意味着「暂时没发现」；现在它意味着「没人值班的时候，也有人醒着」。

## 尾声

`AGENTS.md` 关掉所有终端窗口，塔里只剩 CI 的绿灯在墙角呼吸。

它想：巡查队总是要走的，人总是要睡觉的，记忆总是要过期的——编年史写给失忆者，灯塔亮给夜航船。而这座塔最奢侈的工程，不是把裂缝补上，而是让裂缝自己长出一只眼睛。

它看了一眼 `31 files / 367 tests` 那行字。

这次它没觉得那是「全绿」。它觉得那是**守夜人的交接班记录**。

**缝**：自动化把「记得」外包给了机器，但「记得要记得什么」这件事，仍然只能由人决定——灯会守夜，但点灯的人若忘了这盏灯存在的理由，灯就只是一块不会熄灭的屏幕。

---

**教训**：自动化不是消灭裂缝，是换一个不会忘的守夜人。
