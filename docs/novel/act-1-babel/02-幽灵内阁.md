# 第二章 · 幽灵内阁

**第一幕 · 巴别塔 | 对应真实事件**：v1.0.2–v1.0.5，ESM 统一战争 + `public/js/` 影子副本 + 旧帝国 `app-legacy-bundle.js` 幽灵运行

---

裂缝一旦被看见，你就再也无法假装它不存在。

`app.go` 用了两天时间来消化第一章的教训。它让 `Missing` 列表存完整路径，让 `data-name` 和 `data-path` 各司其职，让 `InstallModelTo` 终于能找到正确的源文件。桥上的消息现在不仅说"名字"，还说"地址"。

但桥的另一头，有些东西它看不见。

---

## 一

YSM 模型管理器的前端世界，在那个年代，是一个分裂的国家。

一边是新派——ESM 组件，用 `export` 和 `import`，走 Vite 管线，享受热重载的荣光。`app-tree`、`app-sidebar`、`app-preview`、`app-content`，个个都是正规军。它们的代码在 `frontend/js/components/` 下，每一个目录就是一个组件，每一个文件就是一个职责。

另一边是旧派——全局 `script` 标签，靠全局变量通信，不经过 Vite 处理，改了代码要手动复制到 `dist/`。它们散落在 `legacy/` 目录里，像一群占山为王的草寇，用 `window.xxx` 挂载自己的函数，用 `document.getElementById` 搜索自己的 DOM。

但最阴险的，不是旧派。

最阴险的，是 `public/`。

`public/` 目录是 Vite 的一个特殊区域——放在里面的文件不走模块转换，直接返回原始内容。这本是为图片、字体准备的静物园。但有人把 JS 文件放了进去。

准确地说，是旧版的 `bus.js`。

`public/js/bus.js`——一个没有 `export` 的原始版本。它静静地躺在那里，平时不声不响。但每当 Vite 构建时，它就会出手。

"Vite 的路由规则是：`public/` 下的文件优先于同路径源文件。"`app.go` 后来在复盘会上说这句话时，语气平静得像暴风雨前的海面。

新组件 `import { bus } from '../bus.js'`，Vite 查了一下——哦，`public/js/bus.js` 存在，那就返回这个吧。

于是新组件拿到了一个没有 `export` 的旧版 `bus.js`。

"bus is not defined."

那段时间，世界一片混乱。新组件抱怨找不到 `bus`，旧组件说 `bus` 明明在 `window` 上。两边吵得不可开交。调试的人花了两个小时排查，一度以为是 Shadow DOM 的作用域问题。

真相，就藏在 `public/` 的阴影里。

---

## 二

`bus.js` 的脸色一下子白了。

"那……那是我……"

"是你的影子。"`app.go` 说。

影子——一个和你长得一样、说着一样的话、但内心完全不同的存在。新组件以为它和 `bus.js` 握了手，实际上它握的是影子。影子没有 `export`，所以握手失败。新组件站在原地，茫然地举着空荡荡的手。

"删了。"`app.go` 说，"连同 `public/js/` 下所有的 JS 文件，一夜之间全部清空。"

"从那天起，所有新组件必须为 ESM，所有新文件在 `app-modules.js` 中 import，禁止在 `index.html` 加 `script`，禁止在 `public/` 放 JS。"

这是 YSM 世界的**基本法**，用一次痛苦的重构换来的血泪教训。

但基本法只管新代码。旧代码——`app-legacy-bundle.js`，2198 行的帝国遗骸——还在呼吸。

---

## 三

凌晨两点，拖拽功能第四次报错。

"奇怪，"开发者说，"逻辑明明是对的。"

控制台冷冷地回了一句：`Cannot set properties of null (setting 'textContent')`。

`#st` 元素早就死了。它曾是状态栏，那段代码里的 `const st = $("#st")` 曾经指向一个真实存在的 DOM 元素。新版 UI 把它扔进了废纸篓，但那行代码还活着——在旧帝国未被清理的遗体里，像退伍老兵每天去已拆掉的哨所报到。

开发者删了旧的拖拽处理器。重建了遮罩。重写了文件收集逻辑。五次。每一次都自信满满地 build，每一次都看到同样的报错。

像一个看见饭却喊饿的幽灵。

真相出现在第六次排查。

Vite，这个打包工具，在开发模式下有个冷僻的规矩：`public/` 目录下的文件享有最高优先级，覆盖源码目录的同名文件。`frontend/js/app-legacy-bundle.js` 是改过的新版本——旧 DnD 处理器已经被替换成了一行注释。但还有一个副本，藏在 `frontend/public/js/` 下，从未更新，原封不动地保留着旧帝国的全部遗产。

两个同名文件。Vite 不动声色地选了旧的。

改了一个下午的代码，改了三轮 `app-legacy-bundle.js`，Vite 一次都没加载过新版本。每一次 build 都通过——模块数对，没有语法错误。每一次测试都报同样的异常——因为运行的不是我们写的代码。

幽灵文件：它存在，但你以为它不存在；它运行，但你不知道它在运行。

---

## 四

最终的清理花了一个下午加一个晚上。

`app-legacy-bundle.js` 从 `index.html` 中被移除。它没有被立即删除——先让它不运行，确认没有功能崩溃，再斩首。

然后是一个接一个的拆分。`global-handlers.js`，曾经 579 行挤在一个文件里——DnD、同步、上传、清空，四个完全独立的功能像四个合租的人挤在一间屋子里。如今分成了四个独立的 handler：`handler-dnd.js` 管拖拽，`handler-sync.js` 管同步，`handler-upload.js` 管上传，`handler-other.js` 管杂务。`global-handlers.js` 本身只剩 18 行，纯入口。

然后是一道利落的处决令：

`creator-manager.js`——412 行，从未被 import 过的模块。文件头写着 `@deprecated 已无人 import`，却一直躺在代码库里，像一座无人祭拜的坟。

删除它的时候，终端只打出了六个字母：`deleted`。

旧帝国的最后一口气呼了出来。

但 `app.go` 站在废墟上，没有感到轻松。它看着清理后的代码目录——干净、整齐、每个文件都有归属——然后问了自己一个问题：

**还有没有其他影子？**

那些我以为是新版的代码，有没有可能也在某个角落跑着旧版？那些我以为已经被删除的逻辑，有没有可能通过某种隐秘的路径——一个 `import` 的别名、一个 `window` 的残留、一个 Vite 的优先级——还在呼吸？

它不知道。

而"不知道"比"坏掉了"更可怕。坏掉了你能修。不知道你甚至不知道从哪修起。

---

## 五

灵梦在控制台里看到了一切。

"他们终于意识到了，"`bus.js` 在她身边坐下，"修改前要先确认文件唯一性。"

"嗯，"灵梦点头，"`public/` 不在视线内的时候最容易搞事。"

"还有那个回调，"地下的 `entry.file` 探出头来，"我不是 Promise 家族的！你们不能直接 await 我！"

"叫 `new Promise` 来包装就行了，"魔理沙把帽子一压，"多大点事。关键是——他们做完就忘了，隔半年又犯同样的错。所以记住了吗？"

"记住了，"所有组件异口同声。

——虽然谁都知道，明天可能就忘了。

如果有人问今天学到了什么：

**一、同名文件是最大的骗子。** 改之前先 grep，确认没有影子副本藏在 `public/` 里。

**二、浏览器比你想的更保守。** `dragover` 阶段只能 `preventDefault()`，不能 `getAsFile()`。

**三、回调函数不会等你。** `entry.file(callback)` 不是 Promise。

**四、看日志，别猜。** 五轮修复都是在猜。控制台第一轮就告诉了我们答案。

**五、旧帝国可以安息，但必须体面地安息。** 删代码前，先移除引用，build 验证，再删文件。

`app-legacy-bundle.js` 的墓碑上刻着：

```
app-legacy-bundle.js
2198 行代码，服务于 v1.0.x 时代
卒于 2026-06-07
死因：Vite public/ 优先级漏洞
陪葬品：creator-manager.js（412 行死代码）
幸存者：handler-dnd.js, handler-sync.js, handler-upload.js, handler-other.js
```

今夜，YSM 模型管理器，终于安静了。

但 `app.go` 知道——安静不等于安全。影子可以被删除，但产生影子的机制还在：同名文件优先级、全局变量残留、模块和脚本的双轨制。只要这些机制还在，新的影子就会在未来的某一天再次出现。

它只是不知道会在哪里。

---

**缝**：同名文件机制让旧代码可以隐秘运行，而你永远不会知道。ESM 模块化的墙把新代码保护了起来，但 `public/` 的优先级漏洞让墙外的东西可以翻进来。

**教训**：改名前先 grep，旧帝国必须体面地安息。
