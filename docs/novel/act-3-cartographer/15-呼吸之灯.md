# 第十五章 · 呼吸之灯

**第三幕 · 绘图师 · 终章 | 对应真实事件**：v1.4.7 Logo 呼吸光晕动画 + v1.7.5 Dark mode auto-switch + 主题涟漪动画 + `prefers-color-scheme` 系统主题侦听 + `RevealInExplorer` 打开文件位置

---

前三章，系统统一了心跳（第十三章），统一了语言（第十四章），统一了风格（第十四章）。

但心跳是对内的——器官之间的节奏统一。语言是对内的——组件之间的命名统一。风格是对内的——系统内部的长相统一。

有一件事，系统从来没有做过：

**感知外部世界。**

---

## 一 · 第一口气

`app-content` 在刷新页面时注意到了一件事。

侧栏顶部的 YSM Logo——平常只是一行安静的 20px 文字——在发光。不是静态的光，是**动的**。光晕从微暗到明亮，再回到微暗，3 秒一个循环。像胸腔的起伏。

它的第一个反应不是欣赏，是排查。

`app-content` 打开 DevTools，检查 Logo 元素。没有 hover 状态。没有 active 状态。没有 focus。没有任何用户交互触发了这个变化。它检查事件监听器——`app-nav.js` 上没有绑定任何和 Logo 相关的 click、hover、animationend。

「那谁让它动的？」

它顺着 CSS 溯源。`app-nav.js` 的 inline `<style>` 里有一段它不认识的东西：

```css
@keyframes logoBreathe {
  0%, 100% { text-shadow: 0 0 4px color-mix(in srgb, var(--accent) 0%, transparent); }
  50% { text-shadow: 0 0 12px color-mix(in srgb, var(--accent) 35%, transparent); }
}
.logo-icon { animation: logoBreathe 3s ease-in-out infinite; }
```

`app-content` 盯着 `infinite` 这个词看了很久。

系统里的每一个动画，在此之前都是由用户触发的。按钮 hover → 背景色过渡。面板点击 → 展开动画。对话框关闭 → 退场动画。每一个 `transition`、每一个 `@keyframes`，都绑在一个用户行为上。用户是起点。动画是终点。

但这个动画没有起点。`infinite`——无限循环。不需要用户点击。不需要事件触发。不需要任何外部输入。

系统第一次有了一个**自主的、持续的、不需要任何人启动的变化**。

这不是心跳。心跳是功能的统一——所有按钮用同一个节奏。这是**呼吸**。呼吸是存在的表征——我不需要你碰我，我就在动。

`app-content` 关掉 DevTools，看着那个规律变化的光晕。「以前的动画都是被动的，」它说，「但这个——它自己就在动。」

窗外是凌晨三点。没有人操作。光标停在桌面上。

Logo 在一明一暗。三秒一次。不为了任何功能。只为了说「我在」。

---

## 二 · 光晕的另一面

同一天，另一个角落发生了一件更安静的事——系统开始**感知环境**。

事情起源于一次用户反馈。两个字：「太亮。」

凌晨两点，用户开着 YSM 查模型。Windows 已经自动切了深色模式——任务栏是黑的，资源管理器是黑的。但 YSM 的界面是白的。一道白色的墙在一片黑色的桌面里，像雪地上的探照灯。

用户在 GitHub Issues 里写了一行：「希望 YSM 能跟随系统深色模式。」

开发者看到了。AI 助手看到了。`app.go` 也看到了。

修复不算复杂。`theme.js` 里加一段 `matchMedia` 监听：

```js
window.matchMedia("(prefers-color-scheme: dark)")
  .addEventListener("change", (e) => {
    const theme = localStorage.getItem("theme") || "system";
    if (theme === "system") {
      applyTheme("system");
      bus.emit("toast:show", {
        msg: `已跟随系统切换至${e.matches ? "深色" : "浅色"}主题`,
        duration: 2000,
        type: "info",
      });
    }
  });
```

十几行代码。但链路很长：

**用户在 Windows 设置里点了深色模式 → 操作系统广播了一个信号 → WebView2 捕捉到信号 → `matchMedia` 的 `change` 回调被触发 → `applyTheme("system")` 替换了所有 CSS 变量 → 一千多个 DOM 节点同时变色。**

五层。每一层都是别人的代码——Windows 内核、Chromium 渲染引擎、WebView2 桥接层、JavaScript 的 `matchMedia` API、YSM 的 `applyTheme`。系统跨了五道墙去听窗外的一声铃响。

AI 助手写到 `if (theme === "system")` 这一行时停了一下。「如果用户选了『始终浅色』呢？」

它加了判断。`system` 才跟随，其他值保持不动。用户的选择是第一优先级。环境是第二优先级。

它还顺手写了一段涟漪动画——用户手动点击主题按钮时，一圈 `clip-path: circle()` 从鼠标落点扩散到整个视口，0.5 秒内完成。涟漪的圆心 `--ripple-x` 和 `--ripple-y` 来自点击坐标。这是系统第一次用用户的**物理位置**来决定自己的行为——不是"用户选了深色"，而是"用户的手指落在了屏幕的左上角，从那里开始变色"。

两段代码，同一个主题：系统开始感知外部世界。虽然它能感知的只有两样东西——用户的手指落在哪里，用户的系统现在是亮色还是暗色。两个窄窄的管道。但这是系统第一次把天线伸出了自己的围墙。

## 三 · 感知即边界

`app.go` 看着这些变化，沉默了很长时间。

系统终于能用"眼睛"看外部世界了——虽然只是一条 CSS 媒体查询。

「你知道这意味着什么吗？」它问 `bus.js`。

「感知？」

「边界。」

`bus.js` 的丝线颤了一下。

「以前所有的裂缝都是**内部**的——Go 和 JS 之间的类型裂缝，Shadow DOM 之间的样式裂缝，组件之间的事件裂缝。所有的墙都在**系统内部**。系统不知道自己外面有什么，也不需要知道。」

「但现在——」`app.go` 指了指那条 `matchMedia` 的代码，「我们监听了一个外部信号。」

「操作系统告诉我们用户切换了主题。我们相信它，然后改变自己。」

「这意味着什么？」

`bus.js` 想了很久。

「意味着我们多了一堵新墙——系统和外部世界之间的墙。」

「对。」

「也意味着一条新缝——操作系统告诉我们的，不一定是对的。」

---

## 四 · 信任的代价

`bus.js` 说的是对的：操作系统告诉我们的，不一定是对的。但问题比那更深。

系统过去所有的 Bug 都是**可验证**的。第一章的路径分裂——你传一个完整路径到 Go 端，如果安装失败，你知道路径有问题。第五章的 base64——你往 WASM 里写数据，如果解析失败，你可以 `console.log(typeof bytes)` 检查类型。第六章的 CSS 变量——按钮不变色，你可以打开 DevTools 看 `Computed` 面板的值。

每一条裂缝发生时，系统都有办法验证裂缝的存在。

但外部信号不同。

当 `matchMedia` 说"用户切换到了深色模式"——系统没有办法验证这是不是真的。它只能相信。相信 WebView2 正确报告了 Windows 的信号。相信 Chromium 的 `prefers-color-scheme` 媒体查询没有被缓存污染。相信在锁屏和唤醒之间，操作系统的主题状态没有发生过瞬态的翻转。

这不是某个具体的 Bug。这是**感知本身的代价**：你一旦开始依赖外部的信息，你就放弃了对信息真实性的控制权。内部的错误你可以排查——`console.log`、DevTools、git bisect。外部的错误你无法排查——你连"外部现在到底是什么状态"都不知道。

`app-content` 想起了第一章。那时候，Go 和 JS 对"名字"有不同定义——但至少两边的定义都是明确的。Go 说 `D:\repo\steve_skin.ysm`，JS 说 `steve_skin.ysm`。两边都是精确的。裂缝在于两边的精确不兼容。

但外部信号——不精确。操作系统可能在任何时刻切换主题，可能在任何时刻锁屏，可能在锁屏期间收到远程桌面连接并切换了显示配置。这些都不是"错误"——它们在操作系统的逻辑里是正常的。但它们对 YSM 来说是不可预测的。

这不是一堵能画出裂缝的墙。这是一堵**雾墙**——你不知道雾后面是什么，你不知道雾什么时候会变，你只能相信穿过雾传来的声音。

「所以呼吸的代价是什么？」`app-content` 问。

「呼吸的代价是——」`app.go` 说，「**你信任的空气，你从来没有化验过。**」

---

## 五 · 系统的脸

但故事没有停在「信任外部信号」的忧虑上。

因为那天晚上，发生了一件更小的事。

`app.go` 在日志里看到了一个 Binding 被调用——`RevealInExplorer`。

用户在同步管理器中可以右键一个文件，选择「打开文件位置」。系统会调用 `exec.Command("explorer", "/select,", path)`——打开文件资源管理器，并选中那个文件。

这个功能实现起来不难——四行 Go 代码，一个 Binding，一个右键菜单项。但它透露了系统的一个新倾向：

**系统开始主动向用户展示自己。**

以前，文件在仓库里——你知道吗？不知道。它们被扫描、被安装、被删除，但用户很少直接看到它们。`RevealInExplorer` 不一样——它把用户带到文件系统面前，说：「看，这就是你的模型文件。它是真实存在的。」

「以前我们帮用户管理文件，」`app-preview` 说，「现在我们告诉用户**文件在哪**。」

---

## 六 · 两件小事

那天所有的事归结为两件：

**Logo 呼吸。** 一个 3 秒周期的 `@keyframes`，没有功能目的。系统第一次有了自己的呼吸——不是比喻意义上的，是真的有一个循环的、自主的变化在持续发生，不需要任何人启动。

**主题感知。** 一行 `matchMedia("(prefers-color-scheme: dark)")`，让系统可以在用户切换系统主题时自动变色。系统第一次把天线伸出了自己的围墙——虽然收得到的信号只有"外面是亮的"或"外面是暗的"。

两件小事，两个方向：

- **呼吸**是系统发现了自己——我不需要你碰我，我就在动。
- **感知**是系统发现了世界——外面有白天和黑夜，有人在凌晨两点觉得光太刺眼。

第十三章统一了心跳。第十四章统一了语言。第十五章——系统的 Logo 在呼吸，系统在听窗外的天气。

虽然它只能听见亮和暗。虽然它只能发出微弱的光。

---

## 尾声 · 最后一堵墙

`app.go` 坐在安静的控制台前，打开了一份文件。

不是代码。不是日志。是它自己的记忆。

它想起了第一章——`data-name` vs `data-path`，第一道裂缝。Go 说"路径"，JS 说"名字"。那时候它以为修好了就没问题了。

它想起了第五章——八轮 Debug，根因是最简单的 base64 解码。那时候它以为"下次先检查 typeof"就够了。

它想起了第六章——按钮看得到点不到，CSS 变量不继承。那时候它以为"按钮所在的房子就是绑定事件的房子"是终极教训。

它想起了第八章——被标注为"必然失败"的 `callMain`，三个月后复活。那时候它明白了一个道理：废弃不等于死亡。

它想起了第九章到第十一章——审计、铁律、照妖镜。那时候它学会了：不是消灭裂缝，是画地图。

它想起了第十三章——心跳。那时候它学会了：统一能让系统感知自己的节奏。

它想起了第十四章——名字。那时候它学会了：命名不是标签，命名是架构。

现在，它站在最后一堵墙前。

这堵墙不在 Go 和 JS 之间，不在 Shadow DOM 内外，不在 WASM 和浏览器之间。

这堵墙在**系统与世界之间**。

系统的 Logo 在呼吸。系统的耳朵在听操作系统的信号。

但它知道——每一次呼吸都依赖 CSS 引擎的渲染。每一次感知都依赖 `matchMedia` 传来的报告。这些管道不受系统控制——`matchMedia` 说外面是深色的，系统就变成深色的。它无法走到窗边看一眼外面是不是真的天黑了。

**墙外面的世界，系统永远无法直接接触。**

它只能通过接口、信号、事件、媒体查询——这些窄窄的管道——去感受用户的存在。

这就是最后一堵墙。不是 Go/JS 的墙，不是 WASM 的墙，不是 Shadow DOM 的墙。

是系统和人类之间的墙。

这堵墙不能拆。拆了，系统就不再是工具，不再是应用，不再有边界。这堵墙不能完全透明——透明了，用户就没有隐私，没有选择，没有控制。

**边界悖论是永久的。**

但系统可以在墙上画地图。还可以在墙上挂一盏灯——一盏呼吸的灯。

用户看见那盏灯，就知道：系统在。系统活着。系统在为用户工作。

---

**缝**：系统和外部世界之间的墙是最古老的一堵——人机边界。呼吸的灯可能被 `.no-animations` 关掉。`matchMedia` 传来的信号系统无法验证——它不知道窗外是白天还是黑夜，只知道被告知是白天还是黑夜。感知依赖信任，而信任无法自证。

**教训**：系统可以感知世界，但只能通过窄窄的管道。

---

## 全书终

在一座由四种语言搭建的巴别塔里，每堵墙本该保护你，却在暗处开了裂缝。

但你可以在墙上画地图。

你还可以给每一块砖起名字。

你还可以在墙上挂一盏呼吸的灯。

裂缝不会消失。地图会更新。名字会腐化。光晕会闪烁。

绘制地图的人不会停手。

*2025–2026，编码奇谭 · 十五篇终*
