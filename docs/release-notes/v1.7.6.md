# v1.7.6 — 对话框动画 + 按钮反馈 + 页面过渡

**发布日期：** 2026-06-16

---

## 🎬 P0: 对话框入场/退场动画

所有模态对话框（重命名、标签编辑、批量重命名、高级筛选、确认框、输入框、选择框）现在支持：

- **入场**: overlay fade-in (150ms) + box scale(.95)→scale(1) 弹性放大 (200ms)
- **退场**: overlay fade-out (120ms) + box scale(1)→scale(.95) 缩小
- **防重复**: `_closing` 标志防止动画期间重复触发

**修改文件**:
| 文件 | 改动 |
|------|------|
| `components.css` | 新增 `dlgFadeIn/Out`, `dlgBoxIn/Out` 关键帧 + `.dlg-closing` 类 |
| `modal.js` | 新增 `closeDlg()` 工具函数，所有对话框统一使用 |
| `rename.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `tag-editor.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `adv-filter.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `batch-rename.js` | 添加 `.dlg-closing` 类 + 延迟移除 |

## 🖱️ P0: 按钮 :active scale 反馈

所有按钮点击时缩小到 97%，提供触觉反馈。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `components.css` | `.btn-base:active { transform: scale(0.97); }` |
| `shared-styles.js` | 同上（Shadow DOM 按钮） |

## 📄 P1: 页面切换淡入

导航切换时新页面从下方 6px 处淡入 (200ms)。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `content-css.js` | `@keyframes pageIn` + `.page { animation: pageIn .2s ease; }` |

## 🔍 P1: 预览面板内容过渡

选中模型后预览内容从下方 4px 处淡入 (200ms)。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `preview-css.js` | `@keyframes previewIn` + `.content > * { animation: previewIn .2s ease; }` |

## ⚙️ P2: 设置页高级面板展开/折叠

"高级设置"面板使用 max-height 过渡实现弹性展开/折叠。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `content-css.js` | `@keyframes advPanelIn/Out` + `.adv-open/.adv-closing` 类 |
| `community-settings.js` | 使用 CSS 类替代 `display` 切换 |

## 🔄 P2: 同步管理器列表淡入

列表内容切换时添加 fade-in 过渡。

**修改文件**:
