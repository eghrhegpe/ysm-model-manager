## 🧱 Resource Types Registry v2

`resource_types.json` 成为单一事实来源，消除 Go 端 2 处硬编码 switch。

| 改动 | 文件 | 效果 |
|------|------|------|
| `resource_types.json` 新增 `storageSubDir` / `configField` / `configFallback` | `resource_types.json` | 新加类型只需改 JSON + AppConfig struct |
| `StorageSubDir` 硬编码 switch → 查注册表 | `go/types/resource.go` `extensions.go` | 6 行 switch 消除 |
| `specificRoot` 硬编码 switch + VRC fallback → 查注册表 + reflect | `resource_bindings.go` | 6 行 switch + 特殊逻辑消除 |
| 新增 `LoadRegistry()` / `RegistryType()` / `SetRegistryPath()` | `go/types/resource.go` | 懒加载 + sync.Once 缓存 |

## ⚡ 扫描缓存事件驱动失效

| 改动 | 文件 | 效果 |
