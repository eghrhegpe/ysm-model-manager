## 🎮 3D 渲染引擎重构（v1.8.6-v1.8.8）

### 坐标系修正

对齐 YSMViewer C# 源码，移除 6 处 X 轴取反，修复骨骼偏移和旋转方向错误。

| 修复项 | 旧代码 | 新代码 | 位置 |
|--------|--------|--------|------|
| Bone pivot X 取反 | `vec3{-b.Pivot[0], ...}` | `vec3{b.Pivot[0], ...}` | `spec.go` |
| 旋转符号 | `eulerToQuaternion(-rx, -ry, rz)` | `eulerToQuaternion(-rx, -ry, -rz)` 三轴取反 | `spec.go` |
| Cube 顶点公式 | `fx := ox - sx` | `fx := ox` | `spec.go` |

### 纹理映射（14 项修复）

| 类别 | 修复数 | 关键修复 |

## 🧱 注册表驱动（v1.8.5）

`resource_types.json` 成为单一事实来源，消除 Go 端 2 处硬编码 switch。

| 改动 | 效果 |
|------|------|
| `StorageSubDir` switch → 查注册表 | 新类型只需改 JSON |
| `specificRoot` switch → 查注册表 + reflect | 含 VRC fallback |
| 前端 3 处硬编码 → `loadResourceRegistry()` | 与 Go 端共享数据源 |
