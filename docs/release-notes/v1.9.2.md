## 📚 Skill 体系重构

4 个 SKILL.md 从内联 bash/PowerShell 迁移为 Python 脚本 + 单行调用：

| Skill | 改前 | 改后 | 脚本 |
|------|------|------|------|
| `doctor` | 7 段 bash grep（70 行） | `python3 scripts/doctor.py` | 116 行 |
| `review` | 9 条 rg 命令 + 3 项检查（120 行） | `python3 scripts/review.py` → JSON → 子代理推理 | 118 行 |
| `line-counter` | 7 段 bash find/wc（88 行） | `python3 scripts/line-counter.py` | 92 行 |
| `ultrawork` | 5 段 bash 内联（60 行） | `python3 scripts/ultrawork.py` | 53 行 |

### 新增技能

| 技能 | 类型 | 说明 |
|------|------|------|
| `release-notes-gen` | 🧠 子代理 | 分析 git 数据，按模板自动写发版说明 |
| `funcmap` | 普通 skill | 提取全项目函数/类型注释，生成 994 条映射表 |

### 子代理模式首发

`release-notes-gen` 是第一个 `runAs: subagent` 技能，工作链：

```
Python: git diff --stat + commit log → 结构化 JSON
  → 子代理：读模板 → 分类改动 → 写 v{X.Y.Z}.md
```

`review` 同步升级为子代理模式：Python 扫出违规清单 → 子代理读取上下文 → 输出修复方案。
