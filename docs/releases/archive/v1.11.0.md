## 🚀 核心：Android 全平台支持（ADR-046）

从桌面单平台扩展到 **Windows / Linux / macOS / Android（arm64）** 全平台打包矩阵。

| 改动 | 说明 |
|------|------|
| 全平台构建管线 | `release.yml` 扩展为四平台打包矩阵，`build-release.ps1` 搬运 MikuMikuAR 已验证发版脚本 |
| Android 构建链路 | NDK 交叉编译 + gradle APK 打包，支持 release 签名（keystore 经 GitHub Secrets 注入，缺则降级 debug） |
| PathManager 平台抽象层 | 路径管理按平台拆分（参照 ADR-018 模式），`getVirtualScreen` 平台分支 |
| 存储授权闭环 | `MANAGE_EXTERNAL_STORAGE` 授权引导 + 目录选择平台分支（桌面 Dialog / Android 授权+路径输入） |
| 查看器模式 | Android 固定公共仓库路径读取 |
| Android 系统事件链路 | 系统事件 → 应用事件桥接 |
