# v1.7.13 — UI 优化

**发布日期：** 2026-06-16

---

## ✨ 改进

### 仓库页面
- 文件树选中状态增强：改用 `color-mix` 背景 + 左侧高亮条，视觉反馈更清晰
- 工具栏布局优化：搜索框独占一行，筛选/作者/批量/更多按钮放第二行

### 预览面板
- 空状态优化：增加文件类型提示标签（YSM/MMD/VRC/资源包）
- Tab 栏与操作按钮分离：Tab 行加底边框分隔，操作按钮（骨骼名/放大）右对齐 + 背景色
- 模型结构树形渲染：ASCII `├─`/`└─` 替换为图标（🦴📦📄）+ CSS 缩进

### 仓库元老页
- 统计条重构：健康度 + 数量/大小/禁用/重复 pill 合并为紧凑单行
- 卡片标题加粗加大（`var(--fs-md)` + `var(--fw-semibold)` + `var(--txt)`）
- 热力图柱子增高：最大高度 32→48px，最小 8→4px
- 资历最深卡片名：允许 2 行显示（`-webkit-line-clamp: 2`）
- 今日推荐卡片：左侧 3px 强调色边框 + 统一 padding
- 内联样式提取到 CSS 类

### 主题系统
- 温暖木纹主题标签颜色对比度提升：`--meta-author` #8b4513→#b5651d，`--meta-work` #6a4e3a→#9b4d2a

### 3D 预览
- 新增「🔄 重置视角」按钮 + `resetCamera()` 方法
- 网格线亮度提高：#444488→#6666aa（主线），#333366→#444488（辅线）

## 🐛 修复

- 修复 `ysm-tab-row` 重复定义
