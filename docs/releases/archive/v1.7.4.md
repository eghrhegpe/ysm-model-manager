# v1.7.4 — 社区站点视图迁移至 Go 后端 + 下载后增量提取头像 + 同步管理器 UI 动画化

**发布日期：** 2026-06-16

---

## 🔄 社区站点视图迁移至 Go 后端

- 替换 `fetchCommunityGitHubRepos`/`fetchCommunityResourceTypes` 为 `App.LoadGitHubRepos`/`App.LoadResourceTypes`，避免前端直连 GitHub
- resourceTypes 改为 JSON 字符串解析（`{resourceTypes:[]}`），App 导入前置

## 👤 头像增量提取

- `index.js`: 监听 config-loaded 事件，仓库路径变更后重新提取头像
- `index.js`: 订阅 avatar:refresh 事件，下载完成后增量更新头像缓存
- `download-queue.js`: .ysm 文件下载成功后调用 `CachedCreatorAvatar` + `DebugExtractCreatorAvatar` 提取头像并通知 UI

## 🎨 同步管理器 UI 动画化

- `tpl.js`: 内联样式抽为 CSS 类（sm-item/sm-tab/sm-status-tab/sm-empty/sm-loading/sm-shimmer）
- `tpl.js`: 列表项入场动画 sm-item-in + 交错延迟，空态/加载态用淡入/骨架屏
- `variables.css`: .no-animations 覆盖 sm-* 元素的过渡/动画
- `errors.js`: 新增社区高频错误模式（rate limit/解析/DNS/SSL/连接中断）
