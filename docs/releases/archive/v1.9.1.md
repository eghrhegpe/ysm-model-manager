## 🏗 新功能：蓝图 3D 体素渲染

### 支持格式

| 格式 | 说明 |
|------|------|
| `.litematic` | Litematica 投影文件（独立资源类型 📐） |
| `.nbt` | Minecraft 结构文件 |
| `.schematic` | 经典/新版 Schematic 文件 |

### 功能

- **3D 体素渲染**：Three.js InstancedMesh，环绕/自身旋转 + 速度控制，WASD 平面移动，Space/Shift 垂直
- **分层渲染**：X/Y/Z 轴切换，全部/单层/范围三种模式，滑块+数字输入
- **Tab 布局**：📋 详情 / 🧱 材料列表 / 🎨 3D（对齐 YSM 模型预览）
- **方块名映射**：pre-1.13 schematic 数字 ID → 注册名，注册名 → 中文显示名
- **体素上限可配置**：默认 20 万，上限 1 亿，设置页可调

### 技术实现

| 模块 | 说明 |
|------|------|
| `go/litematic/` | NBT 解析（`github.com/Tnze/go-mc/nbt`）、元数据解析、体素数据构建、方块颜色/ID/中文名映射 |
| `go/litematic/gen/` | `go generate` 代码生成器：预计算 block ID map，替换 776KB JSON→Go map 字面量 |
| `frontend/…/preview-litematic-*.js` | 3D 体素渲染 + 详情 Tab 布局 |
| `resource_types.json` | `.litematic` 拆分为独立资源类型（📐 投影文件） |
| `resource_bindings.go` | 8 个新 Go Binding（ReadLitematicMeta / GetLitematicVoxelData / ReadSchematic / ReadNbtStructure 等） |
