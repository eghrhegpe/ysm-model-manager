## 🐛 3D 坐标变换修复

经过多次坐标变换实验（欧拉角取反排列组合 × 8 种方案），最终确定对齐方案：

| 修复 | 说明 |
|------|------|
| 对齐 ysmview 旋转符号 | 取消所有欧拉角取反 |
| 对齐 ysmview 坐标变换 | pivot/rotation/cube origin 统一 |
| cube from.x | `from.x = origin.x - size.x` 对齐 |
| cube pivot X | pivot X 取反对齐 |
| eulerToQuaternion | Z 轴不取反 |
| 相机定位 | 默认在 Z- 观察正面 → 回到 Z+ 背面 |
| boneDetail 引用顺序 | 修复引用顺序错误 |
| `window._3dDetailEl` | 修复未设置导致详情框不显示 |
