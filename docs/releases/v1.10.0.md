## 🚀 核心：Wails3 平台迁移

自 v1.9.3 起完成从 Wails v2 到 **Wails v3**（`v3.0.0-alpha2.105`）的平台迁移，属内部基础设施升级，用户可见功能与配置文件保持兼容。

| 改动 | 说明 |
|------|------|
| 绑定生成收敛 | 统一走 `npm run generate:bindings`（`wails3 generate bindings -clean=true -ts -i`），产出 `.ts` 由 Vite 重定向 |
| 前端目录重命名 | `frontend/js` → `frontend/src`，全量 import 路径迁移 |
| 清理 v2 遗留 | 删除 `wailsjs` 死目录（v2 遗留 + 嵌套误产物） |
| Wails3 CLI 防线 | 新增 wails3 CLI 拼写检查，活跃文档全量修正 |
| 绑定安全加固 | 绑定层 subpath 穿越校验 + proxy scheme 白名单 |
