## 🚀 CI 基础设施（本版主体）

| 改动 | 说明 |
|------|------|
| 三层缓存 | 4 平台 + test job 加 Go 模块 / wails3 二进制 / npm 缓存，发版下载+编译时间显著下降 |
| 双 workflow 拆分 | `ci.yml`（main/PR 测试）+ `release.yml`（tag 发版），test 门禁抽为可复用 `test.yml`（workflow_call），消除 main/tag 重复 run |
| 打包门禁增强 | 打包 job `needs: [prepare, test]`——test 不过不打包，杜绝"测试失败但 Release 已发" |
| actions 升级 | checkout@v5 / setup-go@v6 / setup-node@v5 / upload·download-artifact@v6（node24 runtime，消 Node 20 弃用警告） |
| 版本单点 | GO_VERSION / NODE_VERSION / WAILS_VERSION 统一走仓库级 Variables |
| helper embed 前置 | test job 构建 `ysm-updater-helper.exe`（修复 CI 缺产物） |
| 脚本卫生 | 补 3 个脚本 JSDoc 文件头，`check-script-hygiene --strict` 归零 |

## 🐛 修复

- 知识卡提醒增强与复核：疑似过时句精确指行、行号偏移/删除行误报/大小写、CONTEXTUAL 大小写 + BOM 容错（ADR-047 工具链）
- `checkUpdateSilent` 类型断言补 null、sync 空 catch、community events 代际守卫与 i18n key（审核反推）
