## 🚀 核心：工坊模型列表虚拟滚动

社区上线后仓库模型索引可顶到 2000 级，全量渲染 DOM 会爆炸。

| 改动 | 说明 |
|------|------|
| 共享原语下沉 | `utils/dom/virtual-scroll.ts`：`calcVisibleRange` + `installScrollSync` 从 app-tree 下沉，加 `topOffset` 参数 |
| 通用组件 | `community/virtual-list.ts`：定高虚拟列表（零高度自动全量回退、阈值 60 行以下直接全量、`destroy()` 移除滚动监听） |
| 接入工坊 | `renderModelList` 走虚拟列表，行高 42px 定高，jsdom 零高度自动全量回退 |
| 全选修正 | 虚拟化后 DOM 只含可见行，全选逻辑改遍历 `currentFiltered` 筛选结果 |

**设计决策**：零高度回退让既有 12 个集成测试零语义破坏，只需把 `replaceChildren(renderList())` 改成 `renderList()`。
