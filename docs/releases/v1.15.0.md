## 🚀 解码引擎重构（ADR-316/317）

| 能力 | 说明 |
|------|------|
| wazero 内存直解 | .ysm 解码切换 wazero 纯 Go 宿主内存直解，Node 子进程桥整条退役；真实样本 V3 75 产物 1.4s 全解出，V2 均解出 |
| Android 首次解码 | 退役 Node 桥后 Android 首次获得加密模型解码能力 |
| Android WebView 桥（P1） | go/ysmwebview 桥请求管理器 + decodeYSMBest 后端选择器（桥就绪 ≤32MB 走桥，否则回退 wazero），桌面/CLI 零漂移；真实 V3 样本走桥 2062ms（含 wasm 冷启动） |
| interpreter/compiler 基准 | 双模式基准落地：V3 样本 0.76s vs 35.6s = 47×，为 Android 端决策提供数据 |
