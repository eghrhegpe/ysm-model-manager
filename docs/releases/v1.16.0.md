## 🩹 功能修复

| 修复 | 说明 |
|------|------|
| 扫描提速 | 目录遍历改 Go 并行工作队列 + worker 池，遍历阶段实测 1.97–3x，**总扫描耗时缩短 5–54%**（库越大越明显）；条目序经 `sort.SliceStable` 恢复字典序，**缓存内容/索引行序/前端展示顺序零变化** |
| 实例目录崩溃 | 资源类型未知或大小写变体时 `FindInstDir` 空指针 panic——类型解析收敛单一来源，不再崩 |
| 社区创作者名乱码 | 前端 `atob()` 产 Latin-1 致非 ASCII 作者名双重编码落盘（曾使 197 条乱码作者按 name 去重失效）；改 `TextDecoder(UTF-8)` 解码 + Go 合并闸 `repairMojibake` 还原入库脏数据，防任何脏源再回流 |
| 进 3D 崩溃 | reflector `REVISION` 断言提级至构造期，mount 阶段崩溃修除 |
| 去重误删整组 | 缺失组容器时回落 `keep-all`（原会删掉第 0 项以外全部）——删除路径改为**向保全倾斜**，不再静默清空 |
| 畸形骨骼丢子树 | `ParentID` 成环时降级挂到组件根，不再整棵子树消失（不可见骨） |
| 水面异常 | 静水态 NaN 退化门（浪高/水位拉到边界不再变 NaN/黑面）；film 形态水位越界致浪静默死平；波陡基准反归一 |
| 旧水面存档迁移 | pool 形态旧存档兜底取中池位，水位不再退化成平面 |
| 多 mesh 部分撤销残留 | render-mode 覆盖账本按材质记账（开线框/X光后只还原第一个材质） |
| 默认辉光过曝 | bloom 阈值换算到曝光前线性 HDR 域，默认开后处理不再整片泛光「亮瞎」 |
| 环境开关跨会话失效 | renderMode.dispose 仲裁戳污染，关预览再开状态可正确恢复 |
| 贴图加载失败文案 | 改为 i18n 键，ja/en 下不再硬编码中文 |

## 🎨 新装默认观感（仅影响新装/无存档首启）

> **老用户升级后观感不变**——这些默认值经存档持久化，只要进过一次 3D 预览，旧存档即携带旧值并被原样恢复（祖父条款）。
> 想尝新可点「重置全部灯光」或菜单手动开关。

| 项 | 新默认 | 效果 |
|----|--------|------|
| 地面来源 | `none` → `solid` | 开箱即有实体承接面，不再是「空天一片」 |
| 参考网格 | 开 → **关** | 不再叠一张亮网格线；承接面已承担 y=0 锚点 |
| 阴影类型 | `hard` → `soft` | PCFSoft 接触阴影更柔和，接地感更自然 |
| 灯光首启 | 线框关 / fill·rim 关 / 环境光降档 | 告别白环境光把方向性填平的「灰平」观感 |
| 水面 | 开 → **关** | 不再有蓝色水膜压在地面上 |
| 水面波场 | 浪高/水位尺度归一 | 原「±2.7m 风暴」改为可控波浪，新增浪高滑杆 |

另：承接面加微噪点与极低微反射（去「塑料感」）；天空云量滑杆提级到基础行；窗口最小尺寸兜底 800×600。

## ⚙️ 引擎与基础设施

- **Rust 扫描基础设施退役（约 3930 行源码 + 1.3GB 构建物）**：v1.15.0 的 Windows amd64 生产构建曾挂 `rust_backend` 标签，Rust 是真实主路径。替换为 Go 并行遍历后——无新增依赖、无 cgo、无交叉编译负担，且 Rust 方案仅快 19%（`go 226ms / rust 184ms`）而 `jwalk` 上游已废弃。扫描行为对用户零劣化。
- **体积光锥进截图**：导出结果与预览一致（光柱不再只在预览里出现）。
- **web 模式明文 ZIP `.ysm` 可解码**：补 PK 魔数通道 + manifest 归一。
- **首载优化**：主 chunk 拆出 three/ammo/wails 等 vendor。
