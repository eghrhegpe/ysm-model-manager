**发布日期：** 2026-06-16

## 🎬 P0: 对话框入场/退场动画

所有模态对话框（重命名、标签编辑、批量重命名、高级筛选、确认框、输入框、选择框）现在支持流畅动画效果：

- **入场动画**：overlay fade-in (150ms) + box scale(.95)→scale(1) 弹性放大 (200ms)
- **退场动画**：overlay fade-out (120ms) + box scale(1)→scale(.95) 缩小
- **防重复**: `_closing` 标志防止动画期间重复触发

**修改文件**:
| 文件 | 改动 |
|------|------|
| `components.css` | 新增 `dlgFadeIn/Out`, `dlgBoxIn/Out` 关键帧 + `.dlg-closing` 类 |
| `modal.js` | 新增 `closeDlg()` 工具函数，所有对话框统一使用 |
| `rename.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `tag-editor.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `adv-filter.js` | 导入 `closeDlg`，替换直接 `remove()` |
| `batch-rename.js` | 添加 `.dlg-closing` 类 + 延迟移除 |

## 🖱️ P0: 按钮 :active scale 反馈

所有按钮点击时缩小到 97%，提供触觉反馈。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `components.css` | `.btn-base:active { transform: scale(0.97); }` |
| `shared-styles.js` | 同上（Shadow DOM 按钮） |

## 📄 P1: 页面切换淡入

导航切换时新页面从下方 6px 处淡入 (200ms)。流畅的页面过渡效果提升用户体验。

**修改文件**:
| 文件 | 改动 |
|------|------|
| `content-css.js` | `@keyframes pageIn` + `.page { animation: pageIn .2s ease; }` |

## 🔍 P1: 预览面板内容过渡

**修改文件**:
| 文件 | 改动 |
|------|------|
| `preview-css.js` | `@keyframes previewIn` + `.content > * { animation: previewIn .2s ease; }` |

## 🔄 P2: 同步管理器列表淡入

列表内容切换时添加 fade-in 过渡效果。同步管理器列表更平滑。

## 🎯 主要亮点

1. **对话框统一动画**：所有模态对话框使用统一的入场/退场动画系统
2. **按钮触觉反馈**：所有按钮点击时缩小，提供清晰的交互反馈
3. **页面过渡效果**：导航切换时页面从下方淡入，提升流畅度
4. **预览内容过渡**：模型选择时预览内容平滑过渡
5. **设置面板动画**：高级设置面板使用弹性展开/折叠动画
6. **列表淡入效果**：同步管理器列表切换时添加淡入过渡
7. **无障碍支持**：.no-animations 模式下禁用所有动画

## 🛠️ 技术细节

- 所有动画使用 CSS 关键帧定义
- 动画时间控制在 120-300ms 之间
- 使用 `cubic-bezier(.34,1.56,.64,1)` 弹性曲线
- 对话框使用 `closeDlg()` 统一管理
- 防重复标志 `_closing` 防止动画期间重复触发
- 无障碍规则确保 `.no-animations` 模式下禁用所有动画
