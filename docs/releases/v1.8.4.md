# v1.8.4 — YSM Model Manager 综合更新

**发布日期：** 2026-06-16

---

## 🎨 动画系统全量重构（v1.7.4~v1.8.0）

### 对话框动画系统
- 所有模态对话框统一入场/退场动画（overlay fade-in + box scale 弹性）
- `closeDlg()` 工具函数统一管理，`_closing` 标志防重复触发
- 涉及：`modal.js` / `rename.js` / `tag-editor.js` / `adv-filter.js` / `batch-rename.js`

### 页面切换与预览动画
- 页面切换淡入（`pageIn` 200ms）
- 预览面板内容过渡（`previewIn` 200ms）
- 设置页高级面板 max-height 弹性展开/折叠
- 同步管理器列表淡入

### 侧栏与导航栏动画
- 侧栏卡片涟漪选中效果（径向渐变）
- 交错瀑布流入场动画（`vcCardIn`）
- Logo 呼吸光晕动画
- 上下文菜单弹出 + 菜单项滑入动画

### 按钮反馈
- 所有按钮 `:active` 时 `scale(0.97)` 触觉反馈
- `.btn-base` 统一过渡

### 主题切换动画
- 主题切换时全屏涟漪动画（`themeRipple`）
- 点击坐标作为涟漪圆心

## ♿ 无障碍支持
- `.no-animations` 新增 10+ 条规则覆盖所有动画
- 包括对话框、页面、按钮、列表、卡片、设置面板等

## 🔄 社区站点视图迁移（v1.7.4）

- 替换前端直连 GitHub 为 Go 后端 `App.LoadGitHubRepos` / `App.LoadResourceTypes`
- resourceTypes 改为 JSON 字符串解析
- 监听 `config-loaded` 事件，仓库路径变更后重新提取头像
- 订阅 `avatar:refresh` 事件，下载完成后增量更新头像缓存
- .ysm 文件下载成功后自动调用头像提取
